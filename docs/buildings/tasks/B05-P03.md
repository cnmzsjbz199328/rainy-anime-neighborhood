## 可直接用于构建的提示词
在冻结的雨夜日式手绘漫画小城中，为 B05-P03 构建「雨宿咖啡店」。真实 3D 建模，可从任意角度观看，采用细墨线、水彩淡洗和赛璐璐明暗，清洁精致的微缩模型质感。无人物、无屏幕 UI、不增加独立底座。

外观：暖米白抹墙、胡桃木框、灰蓝雨棚、小平屋顶。四个立面有明确构造与细节，不把背面留空。室外设备：大玻璃窗、咖啡杯图形招牌、入口垫、伞架、小花盆、后门、空调与排水管。内部透窗可见且用途明确：咖啡机、磨豆机、甜点冷柜、收银台、两人桌、靠窗座、杯架、水槽、备料台、冰箱、储物柜。功能与结构：前部靠窗座与咖啡吧，中部通路，后部备料与后门；橱窗能读出层次。

外部保持冷蓝紫雨夜，内部柔暖光；在营业窗后呈现近、中、后三层深度，避免不透明发光玻璃。生活细节整齐而不过量，招牌原创，小物件与家具遵循统一比例。

局部运动：咖啡热气极淡、灯光稳定、窗雨和檐水。动作很轻，不能每栋都复制便利店自动门或闪烁灯；复用全局降雨、街道反光与遮雨框架。入口、台阶和附属设施不得阻断人行道或占邻地。参照八视图建立同一套屋顶、门窗与楼层；若图片矛盾，优先本任务结构与实际坐标。

先完成可放置的粗模、空间结构与透明窗，再细化室内物件、墨线、材质与雨夜动画；本栋以外保持原状。

### 设计裁决（参考图与实现的差异）
- 门按冻结入口放在 x = -32.5，略偏左而非图中最左；门左侧是小窗与壁灯，右侧大橱窗。
- 左右侧按「站在正面看」理解：LEFT = 世界东面，大落地窗 + 小雨棚 + 圆形挂牌；RIGHT = 世界西面，窄高窗、备料间横窗、热水器、燃气表、空调外机；后勤木栅在东后角（REAR 视图右侧）。
- 招牌采用原创「雨宿り珈琲 / AMAYADORI / COFFEE & CAKE」与自绘杯形图标，不复制参考图文字。
- 室内：前部靠窗吧台 3 座 + 东窗两张双人桌；中部 1.5 宽主通路直通备料间门帘；咖啡吧含冷藏蛋糕柜、收银机、意式咖啡机、磨豆机；后吧台有水槽、台下冷柜、杯架与粉笔菜单；隔墙后为备料间（不锈钢备料台与水槽、冰箱、员工储物柜、后门）。
- 室内暖光用暖色自发光材质 + 叠加光斑，不新增实时光源。

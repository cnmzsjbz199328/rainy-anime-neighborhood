## 可直接用于构建的提示词
在冻结的雨夜日式手绘漫画小城中，为 B02-P02 构建「独栋住宅 2」。真实 3D 建模，可从任意角度观看，采用细墨线、水彩淡洗和赛璐璐明暗，清洁精致的微缩模型质感。无人物、无屏幕 UI、不增加独立底座。

外观：浅色墙面、灰蓝瓦或金属坡屋顶，细木窗框，明显楼板与檐口；本栋变化：鼠尾草绿墙、灰色单坡金属屋顶、窄高前窗。四个立面有明确构造与细节，不把背面留空。室外设备：玄关台阶、邮箱、空调、热水器、雨水管、垃圾分类箱、停车和小花园。内部透窗可见且用途明确：玄关鞋柜、客厅沙发与茶几、厨房冰箱与水槽、楼梯、卧室床与衣柜、卫生间。功能与结构：楼梯真实连接上下层，楼板与隔墙明确；不同住宅有独立窗位和屋顶轮廓。

外部保持冷蓝紫雨夜，内部柔暖光；在营业窗后呈现近、中、后三层深度，避免不透明发光玻璃。生活细节整齐而不过量，招牌原创，小物件与家具遵循统一比例。

局部运动：少量窗户亮灯、檐水、暖窗倒影；无人物。动作很轻，不能每栋都复制便利店自动门或闪烁灯；复用全局降雨、街道反光与遮雨框架。入口、台阶和附属设施不得阻断人行道或占邻地。参照八视图建立同一套屋顶、门窗与楼层；若图片矛盾，优先本任务结构与实际坐标。

先完成可放置的粗模、空间结构与透明窗，再细化室内物件、墨线、材质与雨夜动画；本栋以外保持原状。

### 设计裁决
- 左右按「站在正面看」：本地 -x = 世界西（花园、围栏、空调、热水器），本地 +x = 世界东（车位）。车位在右侧，与 B02-P01（左侧）相反；参考图中门在主体左部，但冻结入口 x = 21 落在可建中线，所以门靠近主体右端，车位放在门的右边，前院花园放在左边。
- 与 B02-P01 的区别：鼠尾草绿墙；灰色立缝金属单坡屋顶（左高右低，主体前后墙顶是三角形延伸）；前墙三扇窄高窗与一层两扇窄高窗；后墙是整面双扇推拉门通后花园木平台；楼梯在右墙侧向前上行，二层平台在玄关上方；板条围栏代替木板饰面带；窗框深棕。
- 室内：玄关鞋柜与伞架、厨房餐厅（窄高窗后）、客厅（沙发、电视、地毯，推拉门帘）、楼梯、WC；二层平台、前部卧室（床、衣柜）、后部书房（书桌、书柜）、浴室（浴缸）。每层有楼板与隔墙；二层楼板在楼梯处开洞并有护栏。
- 局部动画（很轻）：庭院小树轻摆、窗雨痕、屋檐与车位滴水、暖窗缓慢明暗。

### 残留与待验证
- 真机帧率与构图未测。

## 可直接用于构建的提示词
在冻结的雨夜日式手绘漫画小城中，为 B06-P05 构建「独栋住宅 12」。真实 3D 建模，可从任意角度观看，采用细墨线、水彩淡洗和赛璐璐明暗，清洁精致的微缩模型质感。无人物、无屏幕 UI、不增加独立底座。

外观：浅色墙面、灰蓝瓦或金属坡屋顶，细木窗框，明显楼板与檐口；本栋变化：淡蓝灰墙、浅灰平屋顶带女儿墙、转角小窗。四个立面有明确构造与细节，不把背面留空。室外设备：玄关台阶、邮箱、空调、热水器、雨水管、垃圾分类箱、停车和小花园。内部透窗可见且用途明确：玄关鞋柜、客厅沙发与茶几、厨房冰箱与水槽、楼梯、卧室床与衣柜、卫生间。功能与结构：楼梯真实连接上下层，楼板与隔墙明确；不同住宅有独立窗位和屋顶轮廓。

外部保持冷蓝紫雨夜，内部柔暖光；在营业窗后呈现近、中、后三层深度，避免不透明发光玻璃。生活细节整齐而不过量，招牌原创，小物件与家具遵循统一比例。

局部运动：少量窗户亮灯、檐水、暖窗倒影；无人物。动作很轻，不能每栋都复制便利店自动门或闪烁灯；复用全局降雨、街道反光与遮雨框架。入口、台阶和附属设施不得阻断人行道或占邻地。参照八视图建立同一套屋顶、门窗与楼层；若图片矛盾，优先本任务结构与实际坐标。

先完成可放置的粗模、空间结构与透明窗，再细化室内物件、墨线、材质与雨夜动画；本栋以外保持原状。

## 八视图如何使用
FRONT/REAR/LEFT/RIGHT 用于四面门窗与后勤；ROOF TOP 用于檐口与设备；INTERIOR 用于家具、房间、楼板和通路；RAINY NIGHT 与 REAR LEFT 用于体量、灯光和轮廓。左右按站在室外面对正面时的左右理解，不能当作绝对世界东西。正面在世界 N，其它方位据布局旋转。参考图不负责尺寸验收。

- transform (11, 36.6)、rotY π；本地原点在前门，本地 +x = 世界西。转角地块，可建本地 x -4…3；主体 x -1.55…2.85 × z -6.5…0，二层 z -1.2…-6.5（后退），车位 x -3.9…-1.6（站在正面看的右侧）；两层，女儿墙顶 6.0，屋顶空调最高 6.56（限高 9）。实测世界 [8, 36.05, 14.96, 43.17]，建蔽率 40%。

### 设计裁决
- 左右按「站在正面看」：车位在右（本地 -x），与参考图一致。
- 体量：二层后退 1.2，一层前部屋顶做成带矮女儿墙的露台（长凳、花盆、晾晒衣物），同时是前门雨篷；平屋顶带女儿墙与屋顶空调、检修口。
- 本卡与 B02-P04 描述相同，本栋以退台露台、镜像车位、后部二层浴室和楼梯贴车位侧墙向后上行来区分。
- 局部动画（很轻）：小树、露台晾晒衣物摆动，窗雨痕，露台边与车位滴水，暖窗缓慢明暗。

## 可直接用于构建的提示词
在冻结的雨夜日式手绘漫画小城中，为 B06-P03 构建「底层小文具店商住楼」。真实 3D 建模，可从任意角度观看，采用细墨线、水彩淡洗和赛璐璐明暗，清洁精致的微缩模型质感。无人物、无屏幕 UI、不增加独立底座。

外观：底层商业玻璃、上层淡灰墙与暖木阳台、低矮屋顶。四个立面有明确构造与细节，不把背面留空。室外设备：独立住宅入口、店铺入口、阳台、空调与管道、自行车棚、后门。内部透窗可见且用途明确：底层小文具店：纸笔货架、杂志小架、收银台、包装台与小后仓；二层起居厨房，三层卧室。公交候车区不可占用。 住宅有独立楼梯和每层楼板。功能与结构：商住入口分开，住宅楼梯贯通；后勤和停车必须留在退界空间内。

外部保持冷蓝紫雨夜，内部柔暖光；在营业窗后呈现近、中、后三层深度，避免不透明发光玻璃。生活细节整齐而不过量，招牌原创，小物件与家具遵循统一比例。

局部运动：底层暖窗、上层部分亮窗、雨滴与檐水。动作很轻，不能每栋都复制便利店自动门或闪烁灯；复用全局降雨、街道反光与遮雨框架。入口、台阶和附属设施不得阻断人行道或占邻地。参照八视图建立同一套屋顶、门窗与楼层；若图片矛盾，优先本任务结构与实际坐标。

先完成可放置的粗模、空间结构与透明窗，再细化室内物件、墨线、材质与雨夜动画；本栋以外保持原状。

### 设计裁决
- 左右按「站在正面看」：本地 -x = 世界东（店面、阳台、车棚），本地 +x = 世界西（住户门、空调、垃圾笼）。参考图的自行车棚在左侧后部，照此放在店面一侧后半段（可建宽度够，主体只用 6.0），不再像 B04-P05 / B06-P01 / B06-P02 放在住户门一侧。
- 与前三栋商住楼的区别：进深最浅（4.4，U 形楼梯行程改为 14 级 × 0.17）；深绿木框招牌「やました文具店」加铅笔图标与斜短檐，不用象牙灯箱；店门左侧挑出一块「文具」旗牌；屋顶用立缝金属板（立边）而非瓦，屋脊上是带百叶的通风箱与卫星天线，没有水箱和电视天线；屋后门做成库房后门；店门前是黑板与促销推车，不是价目牌；三层阳台栏杆上有风车。
- 店内：窗边阶梯展台（笔记本与笔筒）与明信片转架、东墙纸笔整面货架、双面笔记本岛架、收银台与价目板、隔墙侧杂志小架、后部包装台（卷纸架、丝带）、门帘后的小库房。主通路 ≥ 0.9（货架到岛架 0.95）。二层为矮圆桌起居、两人餐桌与厨房；三层卧室，书桌靠阳台窗。
- 门前 FrontW 分组的包围盒必须离门中心 ≥ 0.35 半净宽之外，否则 C12 的通行路径会在门口被堵死；最后拿掉了门边的花盆。
- 车棚同样并入主体分组，遮雨区第一块取屋顶与车棚的并集（C12 要求单块遮雨区覆盖主体步行占地）。
- 局部动画（很轻）：左端旗牌轻摆、三层阳台风车缓转、窗雨痕、屋檐/车棚滴水、店窗与上层窗暖光缓慢明暗。

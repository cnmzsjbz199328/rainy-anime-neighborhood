## 可直接用于构建的提示词
在冻结的雨夜日式手绘漫画小城中，为 B04-P03 构建「公交旁口袋公园」。真实 3D 建模，可从任意角度观看，采用细墨线、水彩淡洗和赛璐璐明暗，清洁精致的微缩模型质感。无人物、无屏幕 UI、不增加独立底座。

外观：水彩绿植、灰石铺路、木坐凳；不出现建筑体块。四个立面有明确构造与细节，不把背面留空。室外设备：树池、灌木、长凳、低灯、雨棚小亭、垃圾桶、排水沟、低围边。内部透窗可见且用途明确：俯视展示步道网络、坐凳避让、集水位置；剖视展示地面与花坛高差。功能与结构：出入口对齐现有行走面，不改公交候车区。

外部保持冷蓝紫雨夜，内部柔暖光；在营业窗后呈现近、中、后三层深度，避免不透明发光玻璃。生活细节整齐而不过量，招牌原创，小物件与家具遵循统一比例。

局部运动：叶片微摆、水面涟漪、低灯反光。动作很轻，不能每栋都复制便利店自动门或闪烁灯；复用全局降雨、街道反光与遮雨框架。入口、台阶和附属设施不得阻断人行道或占邻地。参照八视图建立同一套屋顶、门窗与楼层；若图片矛盾，优先本任务结构与实际坐标。

先完成可放置的粗模、空间结构与透明窗，再细化室内物件、墨线、材质与雨夜动画；本栋以外保持原状。

### 实际尺寸与放置
- 源码 `buildings/B04-P03.js`；layout.js `buildings` 登记 `pocketpark`（雨だまり公園）：平移 (35, 6.4)，rotY 0（正面朝 S，本地 +x = 世界东），统一尺度 1。本地原点在入口缺口的参道轴线上，对准冻结入口 x = 35；地块前缘在本地 z = +1.1，后缘 z = −15.4，x = −9 … +11（入口不在地块中线）。
- 主体（role building）是东侧的四坡顶雨棚小亭：柱距 3.0、屋顶 4.4 × 4.4，台座顶 0.31、檐下 2.65、屋脊含宝珠 3.78（限高 4）；实测世界 [38.54, −1.26, 43.1, 3.3]，步行占地 4.15 × 4.15，建蔽率 5%；遮雨区 1 块（四坡屋顶）19.4 平方单位；门 (35, 6.4) → 入口 (35, 7.5) 净宽 0.7 路径 1.1。
- 附属 23 个分组，均在地块内、最高 3.75：parkSign（名牌石）、parkBin（分类垃圾桶）、parkBenchA/B/C（三张长凳）、parkPond（雨水花园水池）、parkTreeW/C/Ch/NW/N/NE/FW/FE（八棵树）、parkEdgeW/E/N/FW/FE（低围边）、parkLampW/C/E（低灯）、parkGround（草地、石板步道、圆形广场、排水槽、盲道、光斑）。

### 设计裁决
- 左右按「站在正面看」理解：本地 +x = 世界东。参考图的亭子在右前 → 放世界东侧中前部；樱花在右后（东北）；大樟树与水池在左（西侧）。
- 公园没有单一「门」：围边每侧一个分组，前围边按入口缺口拆成 FW/FE 两半（缺口净宽 2.1，门柱灯各在缺口一侧），树与长凳各自成组，任何分组包围盒都不横跨参道轴线。
- 地块类型 park，没有建筑体块：登记主体用小亭（唯一带屋顶的物件），遮雨区即亭顶；长凳、垃圾桶、低灯、围边按分组登记为附属。
- 地块前缘在本地 z = 1.1：门柱灯光斑、名牌石等不得超出，光斑改用小尺寸平面。
- 俯视的「集水位置」用雨水花园表达：水池（涟漪）、卵石排水渠与小亭雨链下的石盆；前缘有排水槽与盲道（与外侧公交候车区对应）。剖视（interior）移除屋顶层，可看到小亭地面、长凳与灯笼；参考图的地下剖面（碎石与排水管）未做。
- 招牌原创：名牌石「雨だまり公園」、小亭横梁木牌「雨宿り」。
- 树冠的摆动只作用于内部叶团（外层叶团静止），保证实测包围盒不随动画漂移。

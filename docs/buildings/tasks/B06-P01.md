## 可直接用于构建的提示词
在冻结的雨夜日式手绘漫画小城中，为 B06-P01 构建「底层药店商住楼」。真实 3D 建模，可从任意角度观看，采用细墨线、水彩淡洗和赛璐璐明暗，清洁精致的微缩模型质感。无人物、无屏幕 UI、不增加独立底座。

外观：底层商业玻璃、上层淡灰墙与暖木阳台、低矮屋顶。四个立面有明确构造与细节，不把背面留空。室外设备：独立住宅入口、店铺入口、阳台、空调与管道、自行车棚、后门。内部透窗可见且用途明确：底层药店：非处方商品货架、处方服务柜台、后部封闭药品柜、办公桌、药品冷藏柜、小等候椅；二层起居厨房，三层卧室。 住宅有独立楼梯和每层楼板。功能与结构：商住入口分开，住宅楼梯贯通；后勤和停车必须留在退界空间内。

外部保持冷蓝紫雨夜，内部柔暖光；在营业窗后呈现近、中、后三层深度，避免不透明发光玻璃。生活细节整齐而不过量，招牌原创，小物件与家具遵循统一比例。

局部运动：底层暖窗、上层部分亮窗、雨滴与檐水。动作很轻，不能每栋都复制便利店自动门或闪烁灯；复用全局降雨、街道反光与遮雨框架。入口、台阶和附属设施不得阻断人行道或占邻地。参照八视图建立同一套屋顶、门窗与楼层；若图片矛盾，优先本任务结构与实际坐标。

先完成可放置的粗模、空间结构与透明窗，再细化室内物件、墨线、材质与雨夜动画；本栋以外保持原状。

### 设计裁决
- 左右按「站在正面看」：本地 -x = 世界东（店面、阳台），本地 +x = 世界西（住户门、空调、车棚，临西侧道路）。
- 与 B04-P05 的区别：绿色帆布雨篷与「ひなた薬局」白十字招牌、「処方せん受付」；店内为药店——窗边 OTC 货架与旋转架、候药椅与资料架、中央货架岛、收银台、东墙冷藏柜、带亚克力隔板的处方柜台、后墙带药抽屉柜与员工桌；黑板「お薬の相談」。上层客厅厨房与卧室与 B04-P05 相同。
- 车棚同样并入主体分组，遮雨区第一块取屋顶与车棚的并集。
- 局部动画（很轻）：窗雨痕、屋檐/雨篷/车棚滴水、店窗与上层窗暖光缓慢明暗。

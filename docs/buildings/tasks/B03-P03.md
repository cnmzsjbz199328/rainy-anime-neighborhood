## 可直接用于构建的提示词
在冻结的雨夜日式手绘漫画小城中，为 B03-P03 构建「旧书店」。真实 3D 建模，可从任意角度观看，采用细墨线、水彩淡洗和赛璐璐明暗，清洁精致的微缩模型质感。无人物、无屏幕 UI、不增加独立底座。

外观：茶褐木框、淡米色墙、暗绿色短檐。四个立面有明确构造与细节，不把背面留空。室外设备：书形招牌、雨棚下封闭展示柜、侧窗、后勤门。内部透窗可见且用途明确：高低书架、杂志斜架、文具抽屉、桌面推荐书、收银柜、包装台与库存柜。功能与结构：书本用批量实例与纹理表现，不能每本增加独立光源。

外部保持冷蓝紫雨夜，内部柔暖光；在营业窗后呈现近、中、后三层深度，避免不透明发光玻璃。生活细节整齐而不过量，招牌原创，小物件与家具遵循统一比例。

局部运动：阅读灯稳定暖光、雨滴与门外微弱倒影。动作很轻，不能每栋都复制便利店自动门或闪烁灯；复用全局降雨、街道反光与遮雨框架。入口、台阶和附属设施不得阻断人行道或占邻地。参照八视图建立同一套屋顶、门窗与楼层；若图片矛盾，优先本任务结构与实际坐标。

先完成可放置的粗模、空间结构与透明窗，再细化室内物件、墨线、材质与雨夜动画；本栋以外保持原状。

### 设计裁决（参考图与实现的差异）
- 左右按「站在正面看」理解：LEFT = 世界西（格子窗与小檐、通风口、盆栽），RIGHT = 世界东（格子窗、储藏间小窗、电表、后侧木栅后勤区）。
- 参考图前檐下左侧为封闭展示柜、门在中右；门固定在地块中线（冻结入口），改为「西窗 + 窗前封闭展示柜 + 中门 + 东窗」。展示柜挂在立面上（主体分组），在雨檐下、可建范围内。
- 参考图后门在后视图右侧（世界西），木栅在左（世界东）：照此放置；空调外机放后墙中间，与参考一致。
- 招牌原创：书形板「古書 / しおり堂」与红色书签带，不使用参考图的「旧书店」字样。
- 书本：每排书架是一个带书脊贴图（512×64，随机宽度、颜色、烫金线）的盒子，UV 随机偏移避免重复；平放书堆和封面朝外的书共用调色板贴图。全部合批，无每本书的光源。
- 室内（按任务卡结构）：近层西窗后「均一 ¥100」低书箱、东窗后三层斜面杂志架；中层两墙高书架（格子窗下为低书架）、两张推荐书平台（书堆、立书、手写推荐卡）、东侧收银柜台（旧式收银机、书堆、绿色玻璃罩阅读灯）与身后包装台（牛皮纸卷、绳、包好的书、上方两层书架）；后层隔墙前文具抽屉柜（30 格小抽屉、笔筒、笔记本）、日历与挂钟，东侧门洞挂靛蓝门帘「しおり」；隔墙后储藏间：三组带门库存柜、纸箱、后门。
- 局部动画：阅读灯与吊灯保持稳定暖光（不动）；玻璃与展示柜雨痕（1 批）、前檐与两侧檐口滴水（1 批）；门外湿地上的店面倒影光条缓慢摇曳（只改材质透明度与贴图偏移，几何静止）。

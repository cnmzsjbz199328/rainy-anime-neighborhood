## 可直接用于构建的提示词
在冻结的雨夜日式手绘漫画小城中，为 B02-P06 构建「独栋住宅 6」。真实 3D 建模，可从任意角度观看，采用细墨线、水彩淡洗和赛璐璐明暗，清洁精致的微缩模型质感。无人物、无屏幕 UI、不增加独立底座。

外观：浅色墙面、灰蓝瓦或金属坡屋顶，细木窗框，明显楼板与檐口；本栋变化：浅杏墙、墨绿屋顶、前门偏侧、方形窗。四个立面有明确构造与细节，不把背面留空。室外设备：玄关台阶、邮箱、空调、热水器、雨水管、垃圾分类箱、停车和小花园。内部透窗可见且用途明确：玄关鞋柜、客厅沙发与茶几、厨房冰箱与水槽、楼梯、卧室床与衣柜、卫生间。功能与结构：楼梯真实连接上下层，楼板与隔墙明确；不同住宅有独立窗位和屋顶轮廓。

外部保持冷蓝紫雨夜，内部柔暖光；在营业窗后呈现近、中、后三层深度，避免不透明发光玻璃。生活细节整齐而不过量，招牌原创，小物件与家具遵循统一比例。

局部运动：少量窗户亮灯、檐水、暖窗倒影；无人物。动作很轻，不能每栋都复制便利店自动门或闪烁灯；复用全局降雨、街道反光与遮雨框架。入口、台阶和附属设施不得阻断人行道或占邻地。参照八视图建立同一套屋顶、门窗与楼层；若图片矛盾，优先本任务结构与实际坐标。

先完成可放置的粗模、空间结构与透明窗，再细化室内物件、墨线、材质与雨夜动画；本栋以外保持原状。

### 设计裁决
- 左右按「站在正面看」：本地 -x = 世界西（前院花坛、方窗客厅、西侧栏杆与设备），本地 +x = 世界东（车位）。参考图的车位在左、门在右；这里主体偏左、车位在右（门在主体右端，「前门偏侧」保留），整体与参考镜像。
- 与前五栋的区别：浅杏墙；墨绿四坡攒尖屋顶（脊只有 1.15 长，带宝珠）；方形窗；绿色小庇与后墙推拉门上的绿色遮阳篷；前院是块石花坛；西侧用黑色栏杆；前几栋住宅依次是前山墙人字坡、单坡、深灰瓦切妻、平屋顶、侧山墙加十字山墙。
- 室内：客厅（扶手椅、沙发、电视、窗帘）、玄关鞋柜、后部厨房餐厅（后墙推拉门）、WC；贴右墙向后上行的直跑楼梯；二层主卧、玄关上方的浴室、后部书房、楼梯平台。每层有楼板与隔墙。
- 局部动画（很轻）：前院小树轻摆、窗雨痕、门庇与前檐滴水、车位滴水、暖窗缓慢明暗。

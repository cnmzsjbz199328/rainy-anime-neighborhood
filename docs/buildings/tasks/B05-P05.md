# B05-P05 — こもれび荘（三层公寓）

## 状态与约束
- 阶段：S2（旧样板升级）；源码：[`buildings/B05-P05.js`](../../../buildings/B05-P05.js)；概念板：[`references/B05-P05.jpg`](../references/B05-P05.jpg)。
- 地块：[-18,34,-6,46]；可建包络：[-17,36,-8,44.5]；主面朝 N，入口在北侧。
- 旧样板门世界坐标 `(-12.3,37.88)` 必须保留。地块正面中点锚为 x=-12，现有门偏西 0.30 m；`doorOffset:-0.3` 将此既有偏移明确记录在建筑登记，C12 继续验证净宽路线。冻结地块和街道设施不移动。
- 统一尺度 1；三层，层高约 2.7 m；含屋顶水箱总高不超过 9.5 m（地块限高 12 m）。

## 设计与实施
米灰抹墙、灰蓝屋顶、暖木栏杆与前廊；首层正门进入门厅，三层住户以窗后家具、隔墙和独立楼板表现。东侧真实侧门与折返外梯连通：每层两跑、每跑 8 级，中间平台设支撑与扶手；屋顶、f2、f3 分别标记，可由建筑视图工具剖开。四立面均有窗洞，屋顶水箱与雨棚登记遮雨区。未新增实时光源；门厅灯做低幅度位置脉动。

## 可直接用于构建的提示词
在冻结的雨夜日式手绘漫画小城中，为 B03-P02 构建「洗衣店」。真实 3D 建模，可从任意角度观看，采用细墨线、水彩淡洗和赛璐璐明暗，清洁精致的微缩模型质感。无人物、无屏幕 UI、不增加独立底座。

外观：灰白瓷砖、柔和青蓝框架、简洁大玻璃。四个立面有明确构造与细节，不把背面留空。室外设备：洗衣图形标识、门旁营业信息、自动售货小柜、后部排气管。内部透窗可见且用途明确：两列滚筒洗衣机、堆叠烘干机、折衣台、洗涤剂投币机、等候凳、清洁水槽。功能与结构：滚筒可见但不闪烁；中央通路贯通到设备维护区。

外部保持冷蓝紫雨夜，内部柔暖光；在营业窗后呈现近、中、后三层深度，避免不透明发光玻璃。生活细节整齐而不过量，招牌原创，小物件与家具遵循统一比例。

局部运动：一台滚筒缓慢旋转、状态灯微亮、玻璃雨线。动作很轻，不能每栋都复制便利店自动门或闪烁灯；复用全局降雨、街道反光与遮雨框架。入口、台阶和附属设施不得阻断人行道或占邻地。参照八视图建立同一套屋顶、门窗与楼层；若图片矛盾，优先本任务结构与实际坐标。

先完成可放置的粗模、空间结构与透明窗，再细化室内物件、墨线、材质与雨夜动画；本栋以外保持原状。

### 设计裁决（参考图与实现的差异）
- 左右按「站在正面看」理解：LEFT = 世界西（小横窗、电表箱、落水管），RIGHT = 世界东（高窗、通风口、排气管、空调外机）。
- 烘干排气管：参考图 RIGHT 在东后侧、REAR 在西侧，互相矛盾；按 RIGHT 与烘干机实际位置（东墙）放在东墙后段，爬梯放在后墙东侧，液化气瓶笼放在西后角（参考图 REAR 在东侧，为避开排气管与爬梯改到西侧）。
- 参考图正面门偏右、玻璃面占满；冻结入口在地块中线，改为「西大玻璃 + 中央双扇推拉玻璃门 + 东窄玻璃 + 实墙（营业时间牌）」，自动售货机放在门东侧实墙前。门扇静止，不复制便利店自动门动画。
- 招牌原创「コインランドリー / COIN LAUNDRY / ふわり」与自绘洗衣机图标；营业时间牌 6:00–23:00「年中無休」。
- 室内（按任务卡结构排布）：近层西玻璃后三连蓝色等候椅与杂志小桌、东侧实墙后两替机；中层西墙三台大容量洗衣烘干一体机（滚筒可见）、东墙三列两层烘干机、中央折衣台（洗衣篮、叠好的衣物）与两辆洗衣推车；后层隔墙前清洁水槽（球鞋洗）、洗剂售货机、公告板与挂钟；隔墙后维护间：燃气热水器与管线、绒毛收集桶、拖把池、扫帚、洗剂货架、后门。
- 室内暖光：暖色自发光材质 + 天花灯带与地面光斑，不新增实时光源。衣物共用一张调色板贴图合批。
- 局部动画：中间一台洗衣机的衣物在滚筒里慢转（约 5 秒一圈），玻璃后淡泡沫层轻微变化；该机状态灯琥珀色缓慢明暗（不闪烁）；玻璃雨痕与雨棚/后雨棚檐水（各 1 批）。

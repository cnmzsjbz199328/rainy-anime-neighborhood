## 可直接用于构建的提示词
在冻结的雨夜日式手绘漫画小城中，为 B02-P04 构建「独栋住宅 4」。真实 3D 建模，可从任意角度观看，采用细墨线、水彩淡洗和赛璐璐明暗，清洁精致的微缩模型质感。无人物、无屏幕 UI、不增加独立底座。

外观：浅色墙面、灰蓝瓦或金属坡屋顶，细木窗框，明显楼板与檐口；本栋变化：淡蓝灰墙、浅灰平屋顶带女儿墙、转角小窗。四个立面有明确构造与细节，不把背面留空。室外设备：玄关台阶、邮箱、空调、热水器、雨水管、垃圾分类箱、停车和小花园。内部透窗可见且用途明确：玄关鞋柜、客厅沙发与茶几、厨房冰箱与水槽、楼梯、卧室床与衣柜、卫生间。功能与结构：楼梯真实连接上下层，楼板与隔墙明确；不同住宅有独立窗位和屋顶轮廓。

外部保持冷蓝紫雨夜，内部柔暖光；在营业窗后呈现近、中、后三层深度，避免不透明发光玻璃。生活细节整齐而不过量，招牌原创，小物件与家具遵循统一比例。

局部运动：少量窗户亮灯、檐水、暖窗倒影；无人物。动作很轻，不能每栋都复制便利店自动门或闪烁灯；复用全局降雨、街道反光与遮雨框架。入口、台阶和附属设施不得阻断人行道或占邻地。参照八视图建立同一套屋顶、门窗与楼层；若图片矛盾，优先本任务结构与实际坐标。

先完成可放置的粗模、空间结构与透明窗，再细化室内物件、墨线、材质与雨夜动画；本栋以外保持原状。

### 设计裁决
- 左右按「站在正面看」：本地 -x = 世界西（车位），本地 +x = 世界东（落地窗、前院、设备带）。参考图正面是门在左、落地窗在右、车位在右；这里为了让门在主体左端、窗在右侧、又不挤出可建宽度，把车位放到了左侧（与 B02-P01 同侧，与 P02/P03 相反）。
- 与前三栋的区别：淡蓝灰墙；浅灰平屋顶带女儿墙与压顶、屋面有两台冷凝外机、检修口、通气管与天线；一层上沿通长的混凝土檐带（兼作门与窗的雨篷）；二层右侧竖木板饰面带加转角窗（正面与东墙各半扇）；钢柱平顶车位；前院是砌块矮墙加黑栏杆。
- 室内：玄关鞋柜伞架、前部客厅（扶手椅、沙发、电视、地毯，大落地窗帘）、后部厨房餐厅（后墙推拉门通木平台）、WC；左墙侧朝前上行的直跑楼梯；二层平台、主卧（转角窗、书桌）、书房、浴室。每层有楼板与隔墙。
- 局部动画（很轻）：前院小树轻摆、窗雨痕、檐带滴水与车位滴水、暖窗缓慢明暗。

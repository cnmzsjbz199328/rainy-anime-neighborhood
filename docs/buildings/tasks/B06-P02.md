## 可直接用于构建的提示词
在冻结的雨夜日式手绘漫画小城中，为 B06-P02 构建「底层理发店商住楼」。真实 3D 建模，可从任意角度观看，采用细墨线、水彩淡洗和赛璐璐明暗，清洁精致的微缩模型质感。无人物、无屏幕 UI、不增加独立底座。

外观：底层商业玻璃、上层淡灰墙与暖木阳台、低矮屋顶。四个立面有明确构造与细节，不把背面留空。室外设备：独立住宅入口、店铺入口、阳台、空调与管道、自行车棚、后门。内部透窗可见且用途明确：底层理发店：两张理发椅、镜面工作台、洗头躺椅与水槽、毛巾柜、工具推车、消毒柜、收银与等候座；二层起居厨房，三层卧室。 住宅有独立楼梯和每层楼板。功能与结构：商住入口分开，住宅楼梯贯通；后勤和停车必须留在退界空间内。

外部保持冷蓝紫雨夜，内部柔暖光；在营业窗后呈现近、中、后三层深度，避免不透明发光玻璃。生活细节整齐而不过量，招牌原创，小物件与家具遵循统一比例。

局部运动：底层暖窗、上层部分亮窗、雨滴与檐水。动作很轻，不能每栋都复制便利店自动门或闪烁灯；复用全局降雨、街道反光与遮雨框架。入口、台阶和附属设施不得阻断人行道或占邻地。参照八视图建立同一套屋顶、门窗与楼层；若图片矛盾，优先本任务结构与实际坐标。

先完成可放置的粗模、空间结构与透明窗，再细化室内物件、墨线、材质与雨夜动画；本栋以外保持原状。

### 实际尺寸与放置
- 源码 `buildings/B06-P02.js`；layout.js `buildings` 登记 `barber`（やまの理髪店）：平移 (21, 23.4)，绕 Y 旋转 π（正面朝 N），统一尺度 1；本地 +x = 世界西。门登记为理发店门（本地原点），世界 (21, 23.4) → 冻结入口 (21, 21)。
- 入口 x = 21 距可建范围两侧各 4.5，主体 6.6 × 5.2（本地 x -4.1…2.5，z -5.2…0），比 B04-P05 / B06-P01 的 4.7 进深更深；屋檐出挑 0.3，阳台至 +0.95，招牌灯箱至 +0.14。
- 三层：地坪 0.3、二层 3.1、三层 5.9、墙顶 8.6；水箱与天线最高约 11.3（限高 12）。主体实测世界约 [16.54, 22.3, 25.5, 29.05]，建蔽率约 58%（≤ 60%）。遮雨区 3 块（屋顶并西侧车棚、阳台板、后雨篷）。
- 分组：barber、barberFrontW、barberFrontE、barberEast（东侧砌块花墙）、barberRear、barberGround。

### 设计裁决
- 左右按「站在正面看」：本地 -x = 世界东（店面、阳台、理发灯柱），本地 +x = 世界西（住户门、空调、车棚）。
- 与 B04-P05 / B06-P01 的区别（按上一轮建议改变）：进深加深到 5.2；店面用象牙白灯箱「やまの理髪店」加剪刀图标，不用雨篷；店门左侧有会旋转的红白蓝理发灯柱；屋顶加不锈钢水箱（钢架落在斜屋面上），去掉屋顶空调；东墙一层不开窗，改为镜面工作台；东侧新增砌块花墙与灌木；二层为和室角（榻榻米、被炉）加沙发电视的起居与厨房，三层卧室床头靠东墙、衣柜靠隔墙。
- 店内：窗边候座长凳与杂志桌、东墙镜面工作台与两张理发椅、工具推车、隔墙侧洗头台与两张后仰洗头椅、门边收银台与价目板、后墙毛巾柜与消毒柜。主通路 ≥ 0.9。
- 车棚同样并入主体分组，遮雨区第一块取屋顶与车棚的并集（C12 要求单块遮雨区覆盖主体步行占地）。
- 局部动画（很轻）：理发灯柱缓慢旋转（纹理偏移）、窗雨痕、屋檐/车棚滴水、店窗与上层窗暖光缓慢明暗。

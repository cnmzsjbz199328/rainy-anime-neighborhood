## 可直接用于构建的提示词
在冻结的雨夜日式手绘漫画小城中，为 B05-P06 构建「独栋住宅 9」。真实 3D 建模，可从任意角度观看，采用细墨线、水彩淡洗和赛璐璐明暗，清洁精致的微缩模型质感。无人物、无屏幕 UI、不增加独立底座。

外观：浅色墙面、灰蓝瓦或金属坡屋顶，细木窗框，明显楼板与檐口；本栋变化：奶油白墙、灰蓝人字坡屋顶、左侧车位、竖长木格窗。四个立面有明确构造与细节，不把背面留空。室外设备：玄关台阶、邮箱、空调、热水器、雨水管、垃圾分类箱、停车和小花园。内部透窗可见且用途明确：玄关鞋柜、客厅沙发与茶几、厨房冰箱与水槽、楼梯、卧室床与衣柜、卫生间。功能与结构：楼梯真实连接上下层，楼板与隔墙明确；不同住宅有独立窗位和屋顶轮廓。

外部保持冷蓝紫雨夜，内部柔暖光；在营业窗后呈现近、中、后三层深度，避免不透明发光玻璃。生活细节整齐而不过量，招牌原创，小物件与家具遵循统一比例。

局部运动：少量窗户亮灯、檐水、暖窗倒影；无人物。动作很轻，不能每栋都复制便利店自动门或闪烁灯；复用全局降雨、街道反光与遮雨框架。入口、台阶和附属设施不得阻断人行道或占邻地。参照八视图建立同一套屋顶、门窗与楼层；若图片矛盾，优先本任务结构与实际坐标。

先完成可放置的粗模、空间结构与透明窗，再细化室内物件、墨线、材质与雨夜动画；本栋以外保持原状。

## 八视图如何使用
FRONT/REAR/LEFT/RIGHT 用于四面门窗与后勤；ROOF TOP 用于檐口与设备；INTERIOR 用于家具、房间、楼板和通路；RAINY NIGHT 与 REAR LEFT 用于体量、灯光和轮廓。左右按站在室外面对正面时的左右理解，不能当作绝对世界东西。正面在世界 N，其它方位据布局旋转。参考图不负责尺寸验收。

- transform (-23, 36.6)、rotY π（首个朝 N 的住宅）；本地原点在前门，本地 +x = 世界西。主体 x -3.3…1.55 × z -6.0…0，车位 x 1.6…3.85（站在正面看的左侧）；两层（地坪 0.3、二层 3.05、墙顶 5.6），最高 7.43（限高 9）。实测世界 [-26.91, 36.02, -19.27, 43.21]，建蔽率 43%。

### 设计裁决
- 左右按「站在正面看」：车位在左（本地 +x），门与主体在右，与参考图一致。
- 屋顶按参考图为前山墙人字坡灰蓝瓦；门庇与窗庇是两个小四坡瓦庇；竖长木格窗；二层小屋檐与右侧小屋面省略。
- 地块比北排深 1.25：主体不变，多出的进深做后院（绿篱、踏石、空调、花盆）。
- 室内：客厅、玄关、厨房餐厅、WC，二层主卧、浴室、书房；楼梯贴车位侧墙向后上行。
- 局部动画（很轻）：小树轻摆、窗雨痕、门庇与前檐滴水、车位滴水、暖窗缓慢明暗。

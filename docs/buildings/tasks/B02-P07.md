## 可直接用于构建的提示词
在冻结的雨夜日式手绘漫画小城中，为 B02-P07 构建「独栋住宅 7」。真实 3D 建模，可从任意角度观看，采用细墨线、水彩淡洗和赛璐璐明暗，清洁精致的微缩模型质感。无人物、无屏幕 UI、不增加独立底座。

外观：浅色墙面、灰蓝瓦或金属坡屋顶，细木窗框，明显楼板与檐口；本栋变化：雾白墙、暖灰金属屋顶、简洁横向窗。四个立面有明确构造与细节，不把背面留空。室外设备：玄关台阶、邮箱、空调、热水器、雨水管、垃圾分类箱、停车和小花园。内部透窗可见且用途明确：玄关鞋柜、客厅沙发与茶几、厨房冰箱与水槽、楼梯、卧室床与衣柜、卫生间。功能与结构：楼梯真实连接上下层，楼板与隔墙明确；不同住宅有独立窗位和屋顶轮廓。

外部保持冷蓝紫雨夜，内部柔暖光；在营业窗后呈现近、中、后三层深度，避免不透明发光玻璃。生活细节整齐而不过量，招牌原创，小物件与家具遵循统一比例。

局部运动：少量窗户亮灯、檐水、暖窗倒影；无人物。动作很轻，不能每栋都复制便利店自动门或闪烁灯；复用全局降雨、街道反光与遮雨框架。入口、台阶和附属设施不得阻断人行道或占邻地。参照八视图建立同一套屋顶、门窗与楼层；若图片矛盾，优先本任务结构与实际坐标。

先完成可放置的粗模、空间结构与透明窗，再细化室内物件、墨线、材质与雨夜动画；本栋以外保持原状。

### 设计裁决
- 左右按「站在正面看」。参考图的门在左、车位在右；门固定在本地原点，车位需要 2.4 宽，主体只能放在门右侧，所以车位在左（车位侧镜像，其余——门偏左端、右侧大窗、右侧前院——与参考一致）。
- 屋顶：参考图 LEFT/RIGHT 的山墙非对称（脊偏后），按此做成前坡 0.4、后坡 0.6 的不对称金属切妻；前立面通长金属雨庇覆盖门与客厅窗。前七栋依次是前山墙人字坡、单坡、深灰瓦切妻、平屋顶、横脊加十字山墙、四坡攒尖，本栋是第一个金属立边咬合屋面。
- 窗：二层三格横向带窗，一层大客厅窗，门左竖缝窗；参考图后墙的空调与热水器改放东侧（东侧要放分类垃圾箱，后墙留给厨房横窗和自行车）。
- 室内：玄关、客厅、岛台厨房、WC（楼梯后）；楼梯贴左墙向后上行；二层主卧、盥洗室、后部儿童房、平台。
- 局部动画（很轻）：小树轻摆、窗雨痕、雨庇与前檐滴水、车位滴水、暖窗缓慢明暗。

### 残留与待验证

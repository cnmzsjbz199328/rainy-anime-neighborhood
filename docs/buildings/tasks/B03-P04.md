## 可直接用于构建的提示词
在冻结的雨夜日式手绘漫画小城中，为 B03-P04 构建「食堂」。真实 3D 建模，可从任意角度观看，采用细墨线、水彩淡洗和赛璐璐明暗，清洁精致的微缩模型质感。无人物、无屏幕 UI、不增加独立底座。

外观：暖灰墙、暗红暖帘、木格窗、低坡金属屋顶。四个立面有明确构造与细节，不把背面留空。室外设备：食品模型橱窗、菜单灯箱、排烟管、后门与垃圾区。内部透窗可见且用途明确：二人桌、吧台、开放厨房、灶台抽油烟罩、冰箱、餐具架、水槽、收银台。功能与结构：后厨与前厅有清楚分界；透窗看见桌椅和食物模型。

外部保持冷蓝紫雨夜，内部柔暖光；在营业窗后呈现近、中、后三层深度，避免不透明发光玻璃。生活细节整齐而不过量，招牌原创，小物件与家具遵循统一比例。

局部运动：灶台微雾、灯箱轻微变化、暖帘极轻摆动。动作很轻，不能每栋都复制便利店自动门或闪烁灯；复用全局降雨、街道反光与遮雨框架。入口、台阶和附属设施不得阻断人行道或占邻地。参照八视图建立同一套屋顶、门窗与楼层；若图片矛盾，优先本任务结构与实际坐标。

先完成可放置的粗模、空间结构与透明窗，再细化室内物件、墨线、材质与雨夜动画；本栋以外保持原状。

### 设计裁决（参考图与实现的差异）
- 左右按「站在正面看」理解：LEFT = 世界西（格子窗、通风口、盆栽），RIGHT = 世界东（格子窗、空调外机、液化气瓶、电表）。
- 参考图屋顶在前视图里呈双坡，侧视图却是单坡向后升高，两者矛盾；按任务卡「低坡金属屋顶」与侧视图取单坡：前低后高，雨水向街面排，前后各一条檐沟。
- 参考图的屋顶空调与排烟管放在屋面后部：照此放置（空调在屋面后东，排烟管在后墙外西侧，绕出后出檐）。
- 门固定在地块中线（冻结入口）：门西为大窗 + 窗前食品模型橱窗，门东为窄格子窗 + 立式灯箱，门上方挂三幅红色暖帘「食 堂」，与参考一致。
- 招牌原创：墙上深木板「ひだまり食堂」、立式灯箱与暖帘上的「食堂」（暖帘上不写店名）；菜单、黑板与吧台上的价目均为自拟。
- 室内（按任务卡结构）：近层西窗后两张二人桌（茶壶、碟子、椅）与东窗后一张二人桌；中层吧台与四只红色吧台凳、吧台上的样品碟、酱油架与茶壶、吊灯，吧台上方挂木板菜单（「お品書き」），东端员工通道口与收银台；后层开放厨房（地砖，与前厅木地板分界）：西后角灶台与排烟罩（炖锅、平底锅）、备料台与案板、刀具架、东后角双门冰箱与水槽、西墙餐具架（碗）；后门在厨房东侧，排烟管经后墙引出。
- 局部动画：灶台与排烟管帽的微雾（Sprite，放在未登记的世界坐标根上，避免动画撑大实测包围盒）、暖帘三幅轻摆、灯箱光晕缓慢起伏；另有窗玻璃雨痕与前檐滴水、门外湿地倒影轻晃。

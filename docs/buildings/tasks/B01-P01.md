## 可直接用于构建的提示词
在冻结的雨夜日式手绘漫画小城中，为 B01-P01 构建「院落型小学」。真实 3D 建模，可从任意角度观看，采用细墨线、水彩淡洗和赛璐璐明暗，清洁精致的微缩模型质感。无人物、无屏幕 UI、不增加独立底座。

外观：米白抹灰、鼠尾草绿窗框、低饱和砖红金属屋顶；主翼与低翼组成真实院落，不做单盒子。四个立面有明确构造与细节，不把背面留空。室外设备：校门、公告栏、自行车棚、排水管、设备间、雨棚、花坛、操场线。内部透窗可见且用途明确：入口鞋柜、教室课桌椅与黑板、图书角、办公室、社区活动室、楼梯与每层走廊、储物柜、卫生间分隔。功能与结构：主翼层间楼板、走廊和楼梯必须贯通；活动室放低翼，院落保留车辆入口。

外部保持冷蓝紫雨夜，内部柔暖光；在营业窗后呈现近、中、后三层深度，避免不透明发光玻璃。生活细节整齐而不过量，招牌原创，小物件与家具遵循统一比例。

局部运动：教室灯分区常亮、屋檐滴水、玻璃雨线；无学生。动作很轻，不能每栋都复制便利店自动门或闪烁灯；复用全局降雨、街道反光与遮雨框架。入口、台阶和附属设施不得阻断人行道或占邻地。参照八视图建立同一套屋顶、门窗与楼层；若图片矛盾，优先本任务结构与实际坐标。

先完成可放置的粗模、空间结构与透明窗，再细化室内物件、墨线、材质与雨夜动画；本栋以外保持原状。

## 八视图如何使用
FRONT/REAR/LEFT/RIGHT 用于四面门窗与后勤；ROOF TOP 用于檐口与设备；INTERIOR 用于家具、房间、楼板和通路；RAINY NIGHT 与 REAR LEFT 用于体量、灯光和轮廓。左右按站在室外面对正面时的左右理解，不能当作绝对世界东西。正面在世界 S，其它方位据布局旋转。参考图不负责尺寸验收。

### 实际尺寸与放置
- transform (-26, -35)、rotY 0；本地原点在教学翼主入口。教学翼 x -13…15 × z -7.2…0，三层，墙顶 10.0、屋脊 11.4、含烟囱 12.41（限高 14）；低翼 x -16.2…-9.8 × z 0…9.2，一层；院落操场 x -9…13.5 × z 2.4…10.2。教学翼实测世界 [-42.71, -42.87, -10.44, -25.26]，建蔽率 23%。
- 遮雨区 3 块：教学翼屋顶 [-13.5, -7.75, 15.5, 0.5]、低翼屋顶 [-16.6, 0, -9.4, 9.7]、大门雨庇 [-2.6, 0, 2.6, 1.75]。

### 设计裁决
- 教学翼在后（北），低翼在西，院落操场在南，校门与车棚在最前；大门正对冻结步行入口 x = -26，东墙留车辆口（z -40）。
- 楼梯用楼梯间内的两跑并排直跑代替参考图的外挂铁楼梯；每层北侧走廊、南侧教室；活动室在低翼。
- 为适配 C12（分组包围盒即障碍），围墙、树、球门等拆成 20 个小分组；低翼屋顶放在主分组的 roof 层以通过遮雨区检查。
- 局部动画（很轻）：树与旗摆动、屋檐滴水、窗雨痕、雨庇滴水，教室灯分区常亮。

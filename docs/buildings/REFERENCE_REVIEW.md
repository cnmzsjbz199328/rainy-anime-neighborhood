# 参考图审查与实现时的裁决

生成方式：内置 image_gen，一地块一次独立生成，共 38 张、每张八视图。生图提示词完整保存在 IMAGE_PROMPTS.json。主图尺寸 1536×1024；提交采用同尺寸高质量 JPEG（quality 92、无色度子采样），不裁剪任何视图。

已查看生成结果：四立面、屋顶、剖视及两个斜视齐全；主体用途、手绘漫画风、室内细节和雨夜冷暖关系可用于建模。它们是概念参考，尚不构成跨视图精确几何一致性或空间尺寸验证。

## 通用裁决
- LEFT/RIGHT 标签仅帮助读取；出现同侧视图相似或标签与斜视不一致时，通过前门与屋顶特征判断实际侧面，由实施 Agent 固定一套几何。
- 小窗、空调、屋顶设备和花盆在不同视图可能有位移或数量差异；以任务卡必需功能为底线，采用固定的位置表建模。
- 招牌文字不作为资产：便利店参考出现 YorozuMart、拉面店出现山田屋，与现有样板名称不同。保留现有こもれび MART／雨音らーめん／こもれび荘；新店招牌可采用任务名或原创日文。
- 小店雨棚和花盆外摆全部收入退界内，不把图里的展示底板、周边铺路、电杆或台阶复制到公共道路。
- 多层剖视是解释空间的展开/截断表现，不能根据画面上下间距计算层高。按任务卡层数建立真实楼板和楼梯，不能复制视觉上未连通的楼梯。
- 私宅的停车左右安排只是外观参考，实际车位接合法临路面且避开既定人行入口。
- 学校参考展示主翼、低翼和院落；保持教学主翼候选 28×8、院落 24×9，以及实际 buildable 的约束，不能为放大图中操场改路。
- 公园剖视的土层、暗沟是概念说明，不要求给现有基座添加大型外露剖面。神社和公园内树木/檐角仍按各自 maxHeight。
- 某些玻璃视图展示额外房间或家具，空间不足时先删次要装饰，保证用途、门洞、通路、储物与层次。

## 提交检查的含义
check_kit.mjs 检查地块覆盖、边界与入口数据、JSON 一致性、文件/链接完整和图片签名；不会证明图像的工程尺寸或美术与真实实现完全一致。实际建筑仍须按 BUILDING_SPEC.md 的验收要求截取模型画面。

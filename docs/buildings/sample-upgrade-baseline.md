- `apartmentPlants`：测得 min `[-1.90,0.33,-4.68]`、max `[-0.50,1.03,-4.32]`、ground `[-1.90,-4.68,-0.50,-4.32]`；登记 max x 为 `-0.47`、max y 为 `1.01`、ground max x 为 `-0.47`。

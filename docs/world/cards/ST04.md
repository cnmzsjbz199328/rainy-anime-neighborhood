# ST04 — 城镇卷成星球的过渡分镜

## 状态与关联
- 类型：全局风格板；规格就绪；参考图待生成；尚未实施。
- [星球统一规格](../WORLD_SPEC.md) · [星球计划](../../../WORLD_PLAN.md) · [卡片清单](README.md)
- 参考图：`docs/world/references/ST04.jpg`（待生成）；生图提示词见 [IMAGE_PROMPTS.json](../IMAGE_PROMPTS.json) 中的 `ST04`。

## 区域与位置
- 区域：全局
- 位置：镜头从城镇上空拉远，弯曲程度从 0 增加到 1。

## 尺度
起始画面约 50 m 高的城镇俯瞰，结束画面为整颗星球。

## 外观与形态
平面的城镇和周围地貌像一张纸慢慢卷起，四周的地貌从雾中出现，最后合成完整的星球，两极冰盖在最后淡入。随着镜头拉远，雨丝和云逐渐散去，到全景时是晴朗的月夜。再推近时反向播放，雨重新出现。

## 色彩与材质
同 ST01。

## 必备细节
八格依次：城镇俯瞰（平面）→ 拉远，周围农田出现，边缘渐隐在雾中 → 地面开始弯曲 → 卷到约一半 → 接近闭合，背面接缝即将合拢 → 完整星球，冰盖淡入 → 星球夜景，道路光带亮起 → 推近回到城镇。

## 动态
本卡即动态分镜。

## 夜间光照
前几格是雨夜，雨随距离淡出；完整星球的几格是晴朗月夜。

## 局部天气
沿用所在地貌的局部天气（见 ST05 与相邻地貌卡）。全景距离总是晴朗月夜。

## 墨线
随距离逐渐简化。

## 相邻与过渡
所有区域。

## 细节层级与性能
不适用。

## 约束与禁止
不要出现屏幕 UI、进度条或文字说明；不要让城镇在卷曲中被压扁。

## 参考图要求
一张横版设计板，内容如下：
- 八格连续分镜：雨中的平面城镇 → 拉远、雨变稀 → 开始弯曲、雨几乎消失 → 卷到一半、云散去 → 接近闭合 → 晴朗月夜下的完整星球 → 夜景光带 → 推近回城镇、雨重新出现

参考图只用于外观、结构和氛围，不能从图上量取尺寸。数值以 world.js（W1 之后）、WORLD_PLAN.md 和本卡为准；图与本卡矛盾时以本卡为准，并在 [REFERENCE_REVIEW.md](../REFERENCE_REVIEW.md) 记录裁决。

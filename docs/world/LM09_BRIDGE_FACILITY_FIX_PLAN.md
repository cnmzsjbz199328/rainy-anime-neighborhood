# LM09 无人站设施侵入桥头引道：定位与实施方案

日期：2026-10-21。状态：**定位完成，实施未开始**。本轮只审查、记录证据和制定方案，不修改场景、不重建、不提交、不推送。

## 1. 定位结论

用户截图红圈中的细杆灯和带橙色顶条、下挂时刻表的站牌，对应 `landmarks/LM09.js` 的 `lm09Street`：

- 站牌：`BOARD_X = 6.0`，局部 `(x,z) = (6,9)`；包含杆、底座、双面站名板、时刻表和四条表格线，源码第 134–139 行。
- 站灯：`STOP_LAMP_X = 6.5`，局部 `(x,z) = (6.5,8)`；5.2 m 细杆、短横臂和暖色矩形灯头，源码第 142 行；对应光池在第 143 行。
- 两件均属于地标自身设施，**不在 `streetlights.js` 普通道路灯表或 `roads.js` 的 `signBus` 实例里**。

地理位置是 **RN01-13 大桥东端、N01-west 西端桥头引道**。实际穿过的是 `N01-west` 的 RD01B 引道路面，而不是 `RN01-13` 桥跨网格。两者的断面、护栏和标线连续，所以用户看到的是大桥路面连续区域。

上一轮只追查普通道路灯和 `signBus`，漏掉了地标的独立灯牌。这次更正：桥灯 `offset = 4.4` 的设施带注释问题不能解释红圈中的穿路，也不是本次修复入口；不据此批量移动三座桥的正常桥灯。当前本地交付页的相关源码与工作树一致，无需假设“旧 index.html”才能复现此问题。用户截图来自哪个浏览器版本没有读取，但当前代码已独立、定量复现了同形制两件设施在该处穿路。

## 3. 历史原因与检查遗漏

1. **W10d 的局部移位**：提交 `4ce13f2293a6ca1a3f6f90f7c9c3fc94143524e0` 将站牌局部 x 从 `-3` 改为 `6`，站灯 x 从 `3` 改为 `6.5`，z 仍为 `9` 和 `8`；注释写的是避让 `N01-west` 铺装路肩。LM09 的局部 +X 指向西侧，这次移动把它们移到了当前弯曲桥头引道范围。这里只确认该提交引入了当前位置，不宣称提交之前所有设施均有正确净空。
2. **约束只检查一侧**：`tools/landmark_specific.mjs:53–79` 的 LM09 设施检查，只要求局部 `minX >= -6.15`（CR01 一侧），没有用 `N01-west` 的最终道路三角面检查这两件设施。向 +X 移动自然能通过这个不等式，却不能保证避开另一条道路。
3. **道路灯检查不覆盖它们**：`streetlight_check` 检查普通道路灯表；地标站灯保留在地标模块，所以普通灯 SL3 的通过不证明这根站灯安全。
4. **地面裁切不移动实体**：`scene.js` 会裁 `lm09Ground` / `lm09Platform` 的地面占地，但不会据此移走 `lm09Street` 的杆、牌面或灯头；地面被道路接替后，旧实体仍在原处。
5. **高度沿用站场锚点**：杆脚用站场的统一高度，桥头引道已经抬升。水平位置错误叠加高度差，形成杆从路面里穿出的现象。仅抬高杆脚会留下车道障碍，不能作为修复。

## 4. 实施范围与步骤

### A. 建立缺陷检查，再选站场内位置

- 给站牌（底座、杆、两面牌、时刻表）和站灯（杆、横臂、灯头、光池）增加稳定设施标识，保持属于 LM09，不收编为桥灯。
- 在 LM09 专项里增加针对**最终世界坐标实体**的道路净空检查：覆盖 N01-west 引道、RN01-13 桥端、CR01、N11 连接路及 LM09 出入口。不得只测试对象中心、局部 x 或只排除某一种道路。
- 开工版检查必须捕获上述两处穿路；之后用相同检查验证修复。

### B. 成套移回站场候车区

- 推荐往站场内缩，减小局部 z，保留站牌与站灯为一组候车设施；不改道路中线、宽度、桥面、桥栏、地标锚点或城镇布局。
- 初步试算站牌 `(5,4.5)`、站灯 `(6,4)` 时，杆脚横距已约为 `-6.65`、`-6.88`，离开引道铺装。但生成道路的路堤边坡仍高于这两点站场基准约 `0.29`、`0.32 m`，**因此这两个点不作为最终坐标，不可直接照抄**。
- 实施时继续向可站立的站场区域选位，按完整底座、牌面、灯臂包围体检查：离桥头铺装/护栏至少 `0.5 m`（拟采用的净空阈值），不与长椅、自行车、电话亭相撞，不堵住站场入口与候车步行路径。检查实际地面支撑，不能放到路堤斜坡或水面；必要时在站场内部调整小型基座，不向道路伸出新地坪。
- 使用同一设施锚点移动杆、牌、灯头、光池，避免只移动杆留下旧灯头或光斑。灯光与天气响应保持现有机制。
- 不直接恢复旧 x：旧位置邻近其他道路，未经同一净空检查不能视为安全。

### C. 检查显示与行驶

- 平面、`uBend=0.5`、球形检查映射后的实体与道路/护栏关系；灯臂正常悬于道路上方与低位杆、牌阻挡车道要分开判断。
- 在最终烘焙的几何和骑行碰撞数据中验证新位置，旧位置不应残留不可见障碍。
- 光池应落在候车区域实际接收面上，不能埋在引道下或沿用旧位置；球形晴天规则保持不变。

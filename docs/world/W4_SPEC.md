# W4 精确规格：样板断面（闸门 G1）

状态：生效，供 [WORLD_AGENT_START.md](WORLD_AGENT_START.md) 的 W4 一轮使用（由 WS 在 2026-10-06 补写）。W4 是单批次交付，**交付后停下，状态设为 `待确认`**，由用户判断风格与性能能否作为全球铺设基准（闸门 G1）。数据来自冻结的 [world.js](../../world.js) 与 [WORLD_LAYOUT_V1.md](WORLD_LAYOUT_V1.md)；外观依据 [cards/ST03.md](cards/ST03.md)、TR01–TR04、BI01–BI03、BI05、RD03–RD05、RD07 各卡与 [WORLD_SPEC.md](WORLD_SPEC.md)。数值以 world.js 为准，图只管外观。

## 1. 范围

- 做：把 ST03 的样板断面按**最终质量**实现：城镇边缘 → 水田 → 弃耕地 → 林缘 → 森林 → 草地 → 海岸 → 浅海。同时写出会被 W5、W6 复用的通用生成器：沿曲线扫出道路横断面（RD03、RD04、RD05、RD07）、实例化植物与小物件、墨线随距离分级、水面着色器。
- 不做：全球其余部分（W5、W6）、RD01/RD02/RD06/RD08 的道路（W5）、LM04 的参道与神社本体（W7，W4 只做入口处的 TR03 内容）、天气系统与距离淡入（W8，W4 只做测试钩子）、弯曲控制。
- 不改：`layout.js`、`world.js`、建筑模块。除第 4 节列出的钩子外，不改默认视角的任何像素。
- 前置：W3 完成。分支 `world/W4`；验收通过后合并 main，不推送。

### 3.3 水面、光与天气钩子

- **雨**：断面在补丁外，现有场景的雨盒被夹在 ±BH（城镇底座）以内，补丁外不下雨。W4 新增视角模式 `window.__scene.view.set({ mode: 'section' })`：该模式下雨盒跟随相机目标、不夹紧；其他模式行为不变（保证默认画面逐位相同）。雨随距离淡出沿用现有曲线（50 m 起淡出，110 m 全无）。
- **其他局部天气**：W4 提供测试钩子 `window.__scene.section.set({ rain: true|false })`，关雨并关水洼涟漪即「晴夜」。真正的天气系统在 W8，这里不做状态机。
- **全景可读光照**：钩子 `window.__scene.section.set({ light: 'rainy' | 'panorama' })`；`panorama` 把月光与环境光提亮到「全景晴朗月夜」的可读水平（仍是冷色夜景，不得变成白天），自动随距离混合留给 W8。
- 水面涟漪：大面积雨点涟漪用水面着色器按网格哈希程序化画圆环（BORROWING_NOTES 的判断），**视觉与城镇水洼一致、实现不同**；同步修改 BI01、BI05 卡里「沿用城镇系统」的说法并在 WORLD_SPEC 记录。涟漪场（波源贴图）只留给零星事件，W4 不做。

### 3.4 实例化与预算（每张卡的预算汇总）

- 树 ≤ 3000 可见实例（BI02）。由此推出本断面外推用的密度上限：把实例加载半径取半空距离 50 m 外加余量 60 m，圆盘面积 π·60² = 11,310 m²，最坏全是森林时密度 ≤ 3000 / 11,310 = 0.27 棵/m²；断面森林约 245 m²（24 m × 10.2 m），预期 ≤ 70 棵。**W6 外推时用同一公式**。
- 草丛卡片、灌木、田间小物件、消波块、木桩与栏杆、路标、电线杆全部 `InstancedMesh`；同一种物件共享几何与材质。不为每个物体生成 EdgesGeometry 墨线（树、草、灌木只在近处按 3.5 的规则描边）。
- 背向镜头的半球不渲染 3D 物件（W3 的包围球剔除已覆盖，W4 对实例组加距离与方向剔除：相机目标 60 m 以外只显示地形纹理）。

### 3.5 墨线（WORLD_SPEC 的距离规则）

| 距离 | 描线对象 |
| --- | --- |
| 地面（视线高 1.6–5 m） | 单棵树、岩石、栏杆、石阶、小建筑与小物件 |
| 半空（约 50 m 外斜俯视） | 林缘、田埂、海岸、道路边缘；不描单棵树 |
| 全景（约 300–400 m 外） | 海岸线、山脊、冰缘的外轮廓，加星球外轮廓的连续深色墨线 |

线色、线宽全星球统一（深蓝灰），距离之间平滑过渡（不跳变），不得每帧抖动（沿用城镇的固定种子抖动方式）。W4 把「距离 → 线层可见度/线宽」做成函数，并暴露 `window.__scene.section.set({ ink: 'auto' | 'ground' | 'aerial' | 'panorama' })` 供检查；自动连续混合在 W8 接到真实相机距离。

## 6. 性能与外推（闸门 G1 的核心数据）

- 基线（W3 之后，SwiftShader，1280 × 800）：默认视角绘制调用 ≤ 2597（W2 基线 2361 的 +10%）。W4 不得让默认视角（`uBend = 0`，非 section 模式）绘制调用上升超过 W3 的 +2%。
- 断面三个距离的绘制调用、三角形、实例数、纹理数、渲染耗时：全部记录。
- **外推表**（写进 PROGRESS，供用户在闸门上判断）：用断面里每 1,000 m² 的 绘制调用 / 三角形 / 实例 / 纹理，乘以 world.js 的面积（forest 7,208 m²、farmland 14,769 m²、grassland 19,785 m²、village 4,823 m²、desert 2,773 m²、lava 1,119 m²、ice 8,407 m²、ocean 31,510 m²）估算整颗星球的上限，再与 ROADMAP 第 4 节第 6 条的预算对比，给出「按这个做法铺满全球是否在预算内」的判断；超出时给出选项（降低实例密度、LOD、纹理化）。
- SwiftShader 的帧时间只作对比；真机项写「待验证」。

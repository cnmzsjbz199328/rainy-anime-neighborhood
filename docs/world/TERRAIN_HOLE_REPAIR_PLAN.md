# 黑色地表与球形穿透：根因审查及修复方案

日期：2026-10-20。状态：审查完成（2026-10-20）；2026-10-21 已在本地 `main` 按本方案实施，结果见第 6 节与 PROGRESS「地形缺面修复」；视觉待用户确认。

范围：用户圈出的环城道路边缘、城镇外围田块之间、山脚地面。依据用户提供的两张截图、当前源码与浏览器网格数据；没有打开新截图或进行视觉验收。工作树已有道路、隧道等未提交修改，本次保留。（2026-10-21 更正：那些道路、隧道修改已于 2026-10-20 提交为 `af8fabf`；下文 `terrain.js` 行号为审查时的行号。）

## 1. 已确认根因：裁切后顶点属性回写错误

`terrain.js:692` 的 `cutTerrainByGround()` 在城镇和地标地面建成后裁去它们占用的地形，调用位置为 `scene.js:450`。

它正确计算了剩余多边形及新增顶点，并生成引用新增顶点的索引，但在 `terrain.js:760` 回写属性时使用：

```js
Object.values(g.attributes).forEach((a, i) =>
  g.setAttribute(a.name, new THREE.Float32BufferAttribute(
    original[i].concat(extras[i]), a.itemSize)));
```

这里 `BufferAttribute.name` 并不等于它在 `geometry.attributes` 中的键。实际运行时 position、normal、color 的 `name` 都是空字符串。因此三次写入都写向 `attributes['']`，后一次覆盖前一次；真正的 position、normal、color 仍是裁切前的数组，新索引却已生效。

结果是索引越界、地形无法正确绘制。受影响范围可以扩大到整块地形绘制批次，不能仅按越界三角形的面积估计缺面。田块等独立网格可能仍显示，形成“田块之间大片黑底”的现象。球形投影不会补回地表，缺面处也就不能遮挡球体远侧。该错误在平面和球形中共同存在，并非只在模式切换时把材质设成透明。

机器证据（当前本地 `index.html`，Chromium / Metal，等待世界生成及首帧完成）：

| 检查 | 当前交付页 | 临时副本仅修正属性回写 |
| --- | ---: | ---: |
| 含空键属性的网格 | 64 | 0 |
| 索引超出 position.count 的网格 | 39 | 0 |
| 含越界索引的三角形 | 2,787 | 0 |

临时副本检查了 2,367 个有索引的非实例/实例 Mesh（不含无索引网格与线对象）。原始逐网格记录：`docs/world/audits/terrain-hole-2026-10-20.json`，包含属性长度、最大索引与包围盒。示例：一个网格 position.count 为 838，最大索引却为 1,252；错误空键属性长 1,253。

对照仅在 `/tmp/terrain-hole-probe.html` 修改了这一句为按 `Object.entries(g.attributes)` 的键回写；正式源码和 index.html 未修改。该对照证明消除了索引错误，不代表所有截图黑区均已视觉复验。

`git show HEAD:terrain.js` 同样存在这处错误，属于既有问题，不是本次工作树中的隧道外包裁切新增。

## 2. 独立风险：道路裁地范围超过实际铺面

`terrain.js:27` 的 `CUT_PAD = 0.12` 和 `:461–464` 的 `routeRow()` 默认将 full footprint 两侧各外扩 0.12 m；只有出口走廊内部分行会限制到 strip 外列。另有 0.30 m 的端头裁切扩展。

这是“路边存在无替代面裁切”的明确风险，但尚未对用户圈出的整段环路做面积与空间对应测量，不能当作已确认的第二根因。先消除第 1 项，再检查剩余细缝；否则损坏网格会干扰覆盖分析。

此外，裁切边与道路边即使平面投影重合，高度、分段或球面细分不同也可能产生裂缝。必须用实际最终显示三角面检查，不能只看 footprint、采样高度或理论路径。

## 3. 为什么已有检查未阻止问题

- `unify_check.mjs` 的相关三角遍历直接按索引读取 position，没有先断言索引范围及坐标有限性。越界读取会产生 undefined/NaN，空间索引的循环可能直接跳过这些面。
- 道路射线检查主要覆盖铺装与路口，不能证明道路外侧和山脚地形完整。
- “没有地面重叠”只证明裁切效果的一部分，不能证明“裁掉的区域均有真实表面接替”。

应先验证几何数据合法，再做空间/射线检查；非法三角面必须 FAIL，不得默默跳过。

## 4. 实施顺序

1. **修复属性回写。** 按属性字典键回写，保留各属性 itemSize、normalized 等语义；使用稳定的属性列表对应原始与新增数组。重新计算包围盒和包围球。参考同文件 `cutGroundMeshes()` 已按键收集属性的方式。不要通过增加内球、背景底板或 DoubleSide 掩盖破损数据。
2. **加入几何合法性闸门。** 裁切后、首次显示前检查地形 position/normal/color 数量一致、坐标均有限、全部索引为有效整数且不越界、无意外空键；球形细分后再检查一次。用会产生新增裁切顶点的案例复现旧版失败，确保新版通过。
3. **测量残余缺口并按来源修复。** 对 CR01 整环两侧、城镇外围以及山脚做覆盖扫描，记录缺口坐标、面积、关联裁切来源与替代表面。只有实测确认过裁后才调整该范围。裁地以最终实际铺面为依据，移除没有替代表面的 pad/cap；桥、隧道、地标地面保持各自的立体语义，不把桥下地面、隧道上山体统一挖掉。必要时使用共享边界顶点、高度与细分，而不是叠加遮洞补丁。
4. **扩大检查范围。** 不仅测道路中心线，还测两侧边界、窄缝、田块之间、山脚及地标接地边。检查平面、uBend=0.5、球形三种状态；球形射线必须命中预期位置附近的近侧表面，命中远侧球面不能算 PASS。边界断裂用边段检查辅助发现，不能仅依赖稀疏采样。
5. **构建与回归。** `python3 build.py`；先 `node tools/measure_samples.mjs`，再 `node tools/layout_check.mjs --png`；运行新增几何/覆盖检查、`terrain_structure_check.mjs`、`road_check.mjs`、`unify_check.mjs --only U2,U5` 与球形切换相关检查。已有 TS1/TS3 失败单独对照记录，不能与本次失败混为一谈。检查 tracked 截图差异，保留其他正在进行的工作。

约束：不改 layout.js 的街道中线、宽度、地块与建筑位置，不引入球形专用备用地面。正式修复后再记录精确验证结果及剩余缺口。

## 6. 实施结果（2026-10-21，本地 `main`，基线 `f7594fe`）

1. **属性回写**：`cutTerrainByGround()` 按 `geometry.attributes` 的键回写，保留各属性 itemSize，经 `getX…getW` 读出的值已反归一化，写成普通 Float32。修复前的页面（`terrain_structure_check --ref HEAD`）三种弯曲状态共 192 个非法网格（每状态 64 个空键属性，其中有越界索引），修复后 0。
2. **几何闸门**：`TERRAIN.geometryIssues()` 与地形自己的闸门 `terrain.gate()`，在占地裁切后、`bend.js` 细分后各跑一次（结果 `terrain.stats.gate`，失败报页面错误）。检查工具各自独立判定：`terrain_hole_check` H1、`terrain_structure_check` TS0、`unify_check` U2/U3-town/U5 遇非法网格直接失败，不再跳过。
3. **残余缺口按来源修复**（修好第 1 项后实测，`tools/terrain_hole_check.mjs` H2/H3）：
   - 道路端帽 0.3 m 裁去了无人接替的地面（LM01–LM07 的死路、J-T07/J-T08 的 RD05 口门）：改为 2 mm（只为让末行不与地形、草地共线）。
   - 道路 0.12 m 外扩在条带收窄处（RD05 端头渐变、路口口门）无人接替：每行裁切不超过条带自己的外列。
   - LM07 冰面贴图（半透明，alpha 约 0.3）被当成占地，下面的冰原地形被挖掉：贴图不再算占地。
   - 城镇街区岛外缘没有外立面、比平原高 0.15 m（W10d），地标场地边缘与地形差几厘米，路口铺装与接线路面在出口走廊里止于条带外列：裁切边上的地形顶点（格网角点与新点一同）取接替表面的高度（`sealOutline`；差 ≤ 1.2 m；先在 T 形接点处拆开相邻三角形；桥轴线 11.5 m 内与桥端 2.5 m 外、隧道轴线 8 m 内与洞口 0.5 m 外不动，结构占地下保留的地面不动；路口铺装与条带相接取较低者）。这是 W10_SPEC W10d U5「占地边缘与地形的高差不超过 0.01 m」的实现，没有加遮洞面。
   - 球面裂缝：城镇外的占地网格（LM04 参道边长 15.8 m，球面下垂 0.35 m）与 LM07 冰面贴图按城镇同一 4 m 规则细分（`bend.js` 的细分同时延长 `userData.local`）。
   - 裁切留下的零宽碎片三角形（对齐后会立成薄墙）在地形裁切中去掉。
4. **检查范围**：H2 取地形全部开放边（10,567 条、5,098 m，每 0.25 m、边外 2 cm），台阶以竖面封住或接替面盖过并扎入地形为封闭；H3 扫 CR01 两侧 ±14 m、城镇外 110 m 方形与十个地标；三种弯曲状态，弯曲态只认当地竖直线上的近侧表面。
5. **结果**：H1、H2（uBend 0.5、1）、H3（uBend 0.5、1）通过；H2 平面剩约 31 m、H3 平面剩 2 点（0.12 m²），清单见 PROGRESS「地形缺面修复」与 BACKLOG「地形缺面修复观察」。

# 全域近景质量专项（WD）

状态：WD0 完成，WD1–WD3 视觉待统一验收。2026-10-16 登记。此专项升级已完成的 W7 地标和旅途设施，不追改 W7 历史验收记录。质量依据是 [BUILDING_SPEC](../buildings/BUILDING_SPEC.md) 的建筑条款；原 W7「城外低一档」要求自本计划起取消。区域疏密、生活状态、夜间主次与隐藏线索保持各自设计。

## 共同验收标准

| 对象 | 近景必须具备 |
| --- | --- |
| 建筑外部 | 四立面和屋顶完整；墙厚、洞口、台基、檐口、梁柱、屋面收边、门窗、雨樋与设备连接有实际构造。 |
| 可见室内 | 玻璃后有空间；主要观察窗可读近窗家具、中部通路、后部隔墙或设备。多层建筑有楼板、楼梯、功能分区和逐层差异。封闭不可见空间保留合理结构。 |
| 功能物件 | 售货机、电话亭、车辆、机械可通过操作面和部件辨认用途；主体、连接、基础完整。 |
| 材质与痕迹 | 木板、瓦、石、金属、玻璃有各自接缝、边缘和表面；纸纹与漫画明暗克制。磨损、水渍、盐蚀和维修痕迹对应使用原因，不均匀撒污渍。 |
| 场地与动态 | 入口连通路径，台阶、排水、围栏收口、设备基础落在统一地形；每栋或设施组 1–3 个主要动态。天气效果接统一天气，球形始终晴朗白天。 |

主要结构、家具用三维几何；文字、木纹、细密网眼、小商品标签可用贴图。远景按屏幕尺寸减少细件，但保留轮廓、门窗节奏和主要色块；从设计时就考虑共享几何、材质、纹理、实例化与合批。近景质量不得用统一减面来满足性能。新增附属件均参与真实模型占地、道路净空、高度和落地检查。

共享组件候选：门窗、瓦屋面、雨樋、木构、站务、船具、设备连接件。共享组件只保证制作一致；每栋建筑仍有独立设计卡，记录入口、四立面、可见室内、设备和使用痕迹。

## 与 W10、天气的衔接

WD0 已完成文档、资产核查和当前基线。WD1 可在已批准的位置与外包尺寸内先做独立结构模型；站台边缘、道路入口、统一地形和基础落地的最终集成须等 W10c 道路接口与 W10d 地面确认，避免返工。W10e–W10g 的生成、外观和合批接口与 WD 共用时逐轮集成，W10h 的 `w10-baseline` 仍以 W10 本身验收为准。前置未完成时不得宣称场地集成通过。

天气 WX1/WX2 按 [天气计划](WEATHER_COMPLETION_PLAN.md) 推进。WD 可先做不依赖天气的模型；檐滴、雨击、雪雾及遮雨登记的最终验收须等 WX2 接入统一效果。球形清朗白天规则不随 WD 改变。保留 `layout.js` 的街道中线与宽度、地块和建筑位置，`world.js` 已确认锚点与路网，以及 LM09 经 W10b 批准的站台 15.5 m、棚西移 3 m 和车挡位置；尺寸冲突按既有变更规则报告。

## WD0 性能基线与每轮交付

当前基线见 [`perf/wd0.json`](perf/wd0.json)：2026-10-16，工作树源版本 `2e78e1c`（含本轮文档改动），Apple M4 / ANGLE Metal / high / 三次冷启动。首个完整画面中位 4,327 ms；默认机位中位 16.7 ms、p95 19.2 ms、2,403 calls、1,590,118 triangles；球形 d140 为 38.0 / 40.4 ms、10,551 calls，d400 为 38.7 / 50.7 ms、10,616 calls。控制台错误 0；HTML 3,031,385 bytes。首帧超过 [W10_SPEC](W10_SPEC.md) §6 的 4 s 预算，球形也未达 17/25 ms 目标；这些是开工遗留，不记作 WD 的通过。工具未输出纹理数，WD1 增加相同机位的 `renderer.info.memory.textures` 采集。WD1 在开工提交上重测同机位，并补 LM09 近景/远景与纹理数，再对升级后复测；机况不同或 W10/WX 已变更时不能直接用本文件计算 WD 增量。

每轮机器检查：`python3 build.py`，相关地标/道路/天气检查，`node tools/measure_samples.mjs` 后 `node tools/layout_check.mjs --png`，离线打开、控制台、真实尺寸和净空、性能对照。固定机位覆盖四面、屋顶、主要室内视线、设备、入口、近中远景与球形；生成图和短看点清单交用户判断，不由 Agent 打开最终画面宣称视觉通过。机器通过后仍为 `待确认`，用户确认才为 `完成`。WD1 首轮重点：候车棚能看见空间、车辆构造可读、售货机操作部件可辨、背面完整。

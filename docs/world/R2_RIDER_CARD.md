## 3. 动作

- 骑行：上游坐姿，踩踏起伏与左右摆；轮转 = v / 0.3；自动档位让踏频在约 86 rpm；倾角 = clamp(atan(v·ω / 9.8) × 1.4, ±0.4)（λ7，向转弯内侧）；车把角 = atan(0.94·ω / v) 截到 ±0.6（λ10）；俯仰 = 前后轮接地点高差 / 0.94。头部随环视方向略转（环视偏角 × 0.6，截到 ±1.0 rad；2026-10-21 RI-02 更正：偏角按 2π 周期取 [−π, π]，前方 ±95.5° 内同上，其后由 ±1.0 rad 平滑回到正前方、镜头正对骑手时为 0，转多圈后回到原视角即回中，见 [骑行交互专项](RIDE_INTERACTION_FIX_PLAN.md)）。
- 停车（速度 < 0.3 m/s）：左脚从踏板落到车左侧地面，车身向左倾 0.08 rad，右脚留在踏板上。
- 推车（U1：石阶、检修梯与栈道坡度 > 15% 的陡段）：鹈鹕下车走在车的左侧，右翼扶左把，左翼自然下垂，双腿按行走距离交替迈步；车身直立、轮子在踏步上滚动，不踩踏。碰撞上推车在石阶处按扛车计（只剩骑手圆形占地，便于在 1.6 m 宽石阶上掉头），画面仍是推车；扛车的画面动作未做，若用户要扛车，另行设计。

## 4. 预算与检查

- 预算（K10）：主体 ≤ 24 次绘制调用、≤ 3 万三角形；自由视角与静态画面不显示主体（启动时建好、隐藏）。
- 绘制调用设计：自行车 11（车架、车架灯、后轮、后辐条、曲柄、踏板、链条、转向组件、前灯、前轮、前辐条）+ 鹈鹕 6（身体、身体描边、脖子、头、头部描边、腿与翅膀）= 17；三角形与实测见 PROGRESS「R2 实施记录」。
- 机器检查 K9：总高 ≤ 1.75 m × s；两轮接地；轮角速度 = v / 0.3（±1%）；倾角、把手角与转向同号；俯仰等于坡度（±0.01 rad）；停住时单脚落地。外观由用户看图判断。

# 第三视角地图漫游：任务锁定稿

日期：2026-10-18。状态：范围已梳理，实施待前置完成；本轮只定任务，不改场景。入口以 `ROADMAP.md` 为准。R0（2026-10-18）：交互数值、固定路线与检查口径见第 6 节；W10f 可走面接口尚未落地，R0 为「进行中」，第 6.9–6.10 节列出待补项。

## 1. 目标与现状

目标是从现有平面地图进入可见骑手和自行车的第三视角，沿统一路网从城镇骑向城外，能停下环视、转弯、折返，并随时返回原自由视角。优先复用「鹈鹕骑自行车」项目的骑手、车与跟随镜头实现，按本项目的画风、地形、道路、天气和单文件构建改造。

## 2. 交互规格

1. 平面地图上可从当前自由视角所看的道路进入漫游；目标不在可走表面时，选择最近的合法起点并让用户知道出生位置。退出时保留进入前自由视角的目标、方位、俯仰和缩放。
2. 移动、转向和环视分离：W/S 或摇杆纵轴前后移动，A/D 或摇杆横轴转向；拖动/触屏右侧环视，松手后保持视线方向，符合现有 C1 决策。角色/行进方向不因单纯环视而改变。再次主动转向时镜头平顺跟随。
3. 镜头在行进方向后方约 3–3.5 m、上方约 0.7–1.4 m，视野约 46°–47° 作为初值，实际按遮挡与道路宽度调节。阻尼不得造成镜头穿墙、穿地、落水或跨越道路边界；窄巷和遮挡处收近并抬高。
4. 可走范围使用 W10f 的统一道路/人行道/公共区域语义。桥、隧道、坡道按实际表面高度连续行进；无道路连接的区域不能靠镜头或角色穿越。道路边界、建筑、路灯、电杆和地标设施应阻挡主体，碰撞不能只靠矩形坐标夹取。
5. 进入/退出、键盘与触屏、失焦清键、地图模式切换都要有明确状态。切到球形地图时退出漫游。保留当前雨夜和当地天气，不引入天气切换规则。

## 3. 可见主体

用户本轮已明确选择**默认可见的原创鹈鹕骑手与自行车**。`DESIGN.md` 的「无人」继续约束静态街景和自由视角；骑行模式中出现受控鹈鹕是本任务的特定例外。可复用上游程序化网格和动画结构，但最终轮廓、配色、材质与细节需适配本项目钢笔线稿与淡彩雨夜风格。轮转、踩踏、停车、转弯与坡度姿态都在验收范围内；速度需按道路尺度重新定标，不能沿用 1.5 m/s 步行值。

- **W10f 计划**（W10_SPEC 2.8 与 W10f 一行）：只规定一个地面采样器、可走表面为路面加人行道加城镇公共区域、相机高度为地面加 1.62 m、删除 `townAvailable`；U7 为城外随机 20 段走通、高度误差 ≤ 0.01 m、W9a 路线照常可走。**没有规定接口形状**：查询函数、表面类别、边界、分层、显示比例都未定义。R1 需要的接口见 6.9。

### 6.2 模式与进入、退出（现在可定）

- **只有一种漫游**：R1 起由骑行取代 W9a 步行，沿用 V 键、右上角按钮（文字改为「骑行 V」/「自由视角 V」）、Esc 退出和 `view.set({ mode: 'roam' })`，不保留步行模式（W10 2.8「一套漫游规则」，D15 不留双模式）。主体只在骑行模式出现，自由视角与静态画面不显示（DESIGN「无人」）。
- **可进入条件**：平面模式、uBend 为 0、不在切换动画中。W10f 删除 `townAvailable` 后不再限城镇。球形模式或切换中按钮禁用，title 写明原因。
- **进入**：按 6.3 找出生点；镜头从当前自由视角用 1.0 s smoothstep 过渡到跟随位（fov 36 → 46，near 0.25 → 0.08），过渡中可以输入；剖视模式随之关闭。
- **退出**（V、Esc、按钮、`view.set({ mode: 'free' })` 或切到球形）：自由视角的 target、yaw、pitch、dist 恢复为进入前的原值（逐位相同），fov 与 near 复原，主体隐藏，输入清零。切球形时先退出，再开始弯曲动画（沿用 `setMapMode` 的顺序）。
- **失焦**（blur、页面隐藏、pointercancel）：清空按键、摇杆归零、结束拖动；车按无输入滑行减速，不残留油门或转向。带 meta、ctrl、alt 的组合键不触发（沿用现状）。
- **天气与灯光**：保持当地天气与雨夜，不加新规则；雨区跟随骑手（`rainBounds` 已用漫游位置）；`weatherView` 的高度改为镜头离实际地面的高度。车灯只用自发光灯面和反光片，不加点光源。

### 6.3 出生点（规则现在可定；可选的面待 W10f）

1. 取自由视角 target 的 (x, z)，接缝内归一到 [xMin, xMax)。
2. 在「行车面」上找平面距离最近的点。行车面包括车行道（城镇主街与支路、RD01–RD05、CR01、桥面）、城镇巷道、RD07 栈道和 RD08 雪道；人行道、W01 和地标场地不作出生面。排除：石阶与检修梯；隧道洞内（投影落在洞内时改到较近洞口外 5 m）；桥下（目标在桥面投影下时，取桥面同一断面）。
3. 朝向：取该点道路切线两个方向中、与自由视角水平视线点积为正的那个；视线与道路接近垂直（|点积| < 0.2）时取路线里程增加的方向。
4. 横向：车行道宽 ≥ 4.5 m 时放在左侧车道中心（宽度的 1/4：主街、RD01、RD02 为 1.75 m，支路 1.5 m，RD03 1.125 m），其余放在铺装中心（RD04 的铺装中心在中线左 0.15 m）。
5. 提示：出生点离 target 超过 2 m 时，屏幕下方显示 3 s「从最近的道路出发：〈道路名或路线号〉，〈距离〉 m」。名称取 `layout.js` 的路名、巷名，或 `world.js` 的路线号和地标名。
6. 默认机位（target (−7, 20)、yaw 2.5）的出生点是 **S0 = (−7, 16.75)，朝西（h = −π/2）**，即便利店门前 R01 的西行车道。R1 起它取代 W9a 的 (−8, 15)。

### 6.5 运动（数值现在可定；表面类别到上限的映射待 W10f）

- **速度**：巡航（W 或摇杆推满）4.2 m/s（约 15 km/h）；起步 1.5 m/s²（2.8 s 到巡航）；松开后滑行减速 0.8 m/s²（从巡航约 11 m 停住）；刹车 3.5 m/s²（1.2 s、约 2.5 m 停住）；倒推上限 0.8 m/s。按表面限速：车行道 4.2，RD05 与城镇巷道 3.5，RD08 雪道 3.0，RD07 栈道 2.5，人行道、W01 与地标场地 2.0（徐行），石阶与检修梯 0.8（推车，见 U1）。进入限速更低的面时以 2.0 m/s² 降到上限，不突变；隧道不另限速；坡度不改变速度，只影响姿态和踏频动画。
- **转向**（运动学单车）：steerCmd 按 λ8 跟随输入；航向角速度 ω = steerCmd × ωmax(v)，ωmax(v) = min(v / 2.2, 3.0 / v)，即最小转弯半径 2.2 m、侧向加速度 ≤ 3.0 m/s²；v < 0.5 时与原地扶车转向 1.2 rad/s 线性混合；倒推时转向自然反向。巡航 4.2 m/s 时 ω ≤ 0.71 rad/s（半径 5.9 m）。
- **姿态**（R2，沿用上游公式）：倾角 = clamp(atan(v·ω / 9.8) × 1.4, ±0.4)，λ7；把手角 = atan(0.94·ω / max(v, 0.5))，截到 ±0.6，λ10；车身俯仰 = 前后轮接地点高差 / 0.94；轮转 = v / 0.3；踏频按上游自动档位；v < 0.3 停住时单脚落地。
- **贴地**：前后轮接地点各自取所在层的表面高度（I1），骑手根节点取两点中点；不离地、不跳。
- **步长**：每帧拆成 dt ≤ 1/60 的子步，每子步位移 ≤ 0.25 m × s；帧长仍截到 0.12 s。
- **接缝**：x 越过 xMin 或 xMax 时，骑手、镜头、阻尼状态和雨区一起平移 ±2πR（同 `BEND.wrapX`），不插值。

### 6.6 碰撞（规则现在可定；边界与碰撞体数据待 W10f）

- **主体形状**：水平胶囊，半径 0.32 m，轴段前后各 0.5 m（总长 1.64 m），高 0–1.75 m，均乘 s。
- **不可越过**：可骑面外缘（路肩以外、边沟、田地、草地、森林、水面）；高差 > 0.05 m 的台阶（城镇路缘 0.13 m 只能从路缘坡口或车道口通过）；坡度 > 15% 的面（石阶另计）；桥护栏、栈道绳栏、隧道侧墙、建筑与地标墙体；面内立杆（巷道路灯、信号灯杆、标志、电杆、导引柱、公交牌、售货机等）。
- **响应**：去掉指向边界的速度分量，沿边界滑行；入射角 > 60° 时停住；不反弹、不摔车、没有其他惩罚。穿透 ≤ 0.02 m × s。
- **分层**：桥面与桥下地面、隧道洞内与上方山体是不同的层，只在登记的连接处（桥台、洞口、坡口、梯端、护栏门）换层。

### 6.7 镜头（数值现在可定；遮挡体数据待 W10f）

- **跟随位**：焦点 = 骑手接地点 + 0.92 m；镜头在焦点后 3.5 m、上 0.70 m（标称高度 = 地面 + 1.62 m，与 U7 一致）；看点在焦点前 1.6 m、上 0.05 m；fov 46°，near 0.08。以上乘 s。
- **环视**：方位偏移 lookYaw 相对行进方向保存，360° 不设限，0.005 rad/px，方向与 C1/W9a 的抓取式一致；仰角 −0.10 至 1.05 rad，默认 atan(0.7 / 3.5) = 0.197，0.003 rad/px，向下拖动视线上抬（同 W9a）。松手后保持，不按时间回正；C 或双击用 0.4 s 回到 0。主动转向时偏移随航向一起转，镜头平顺跟随；单纯环视不改变航向（|Δheading| < 1e-3）。
- **跟随距离**：滚轮或捏合在 2.5–6.0 m 之间调，默认 3.5 m。
- **阻尼**：在骑手的行进坐标系里分轴，纵向 λ6、竖直 λ4、横向 λ3（上游追随镜头的值）。
- **遮挡与约束**（按顺序）：
  1. 从焦点向期望镜头位置做半径 0.2 m 的扫掠，遮挡体为建筑与地标简化体、桥体、隧道衬砌和沿线地形高度。被挡时距离 = max(1.2, 命中距离 − 0.25)；收近立即生效，放远按 λ2；收近时抬高至多 0.6 m（隧道内不抬，且不高于洞顶 − 0.3 m）。
  2. 水平位置不超出可骑面外扩 0.5 m；桥面、栈道和隧道内外扩为 0，即不出护栏、不出洞壁、不落水。
  3. 高度 ≥ 镜头下方同层表面 + 0.12 m；在桥面上 ≥ 桥面 + 0.3 m。
  4. 镜头离任何遮挡体表面 ≥ 0.15 m，近裁面不穿面。
- **窄处**（巷道 3.5 m、W01 2 m、RD05 3 m、栈道 2 m、雪道 2 m）不另设参数，由上面的扫掠和约束自然收近。

### 6.11 机器检查方案（R1 建立，R3 补全；本轮不实施）

新工具 `tools/ride_check.mjs`。测试钩子 `window.__scene.ride`：`get()` 返回位置、航向、速度、层、表面、镜头与遮挡状态；`set({ x, z, heading, speed })`；`step(dt, { throttle, steer, lookYaw, lookPitch })` 以固定 dt = 1/60 推进，不依赖 rAF，结果可复现。页内用纯追踪控制器（预瞄 2.5 m × s，按曲率限速 v ≤ √(3.0 / κ)）沿 `ride_routes.mjs` 的车道线驾驶，并逐步记录输入。

- **K1 走通**：每条路线在「长度 /（0.6 × 限速）+ 10 s」内到达终点，离开可走面 0 次。
- **K2 贴地**：前后轮接地点与 I1 表面之差 ≤ 0.01 m × s；相邻子步高差 ≤ 位移 × 0.15 + 0.005 m × s（石阶推车按踏步高另判）；出口、等级渐变、桥台、洞口单独列出。
- **K3 分层**：桥上全程为桥面层、从不报桥下；隧道内全程为洞内层；只在连接处换层。
- **K4 碰撞**：RC 探针按 90° 和 30° 两种入射角、以该面限速驶入：穿透 ≤ 0.02 m × s；90° 时停住；30° 时沿边滑行并保留 ≥ 50% 速度；RC-02 必须通过；0.12 s 长帧不穿过 0.1 m 立杆。
- **K5 镜头**：每一步镜头都不在遮挡体内，离表面 ≥ 0.12 m × s，满足 6.7 的水平约束；焦点到镜头的视线不被遮挡（允许被挡的步 ≤ 1%，且连续不超过 0.2 s）；巷道与 W01 中距离 ≥ 1.2 m；隧道内离洞壁 ≥ 0.3 m、离洞顶 ≥ 0.3 m。
- **K6 输入**（真实事件，桌面与触屏各一套，做法同 `views.mjs`）：按 W 4 s 后速度 4.2 ± 0.1 m/s；松开后滑行；按 S 在 1.6 s 内停住、继续按则倒推 ≤ 0.8 m/s；A 左转、D 右转（以骑手坐标判号）；停住时 A/D 原地转向；拖动只改 lookYaw，松手 3 s 不回正，抓取方向同 C1；C 与双击回正；滚轮距离在 [2.5, 6] 内；摇杆与键盘给同样输入 2 s 后航向与速度差 ≤ 5%；blur 后无残留输入；V、Esc、按钮退出后自由视角四项逐位恢复；切球形自动退出；球形和切换中按钮禁用。
- **K7 出生**：RS-01–RS-12 的落点、朝向、车道和提示符合 6.3。
- **K8 接缝**：RT-05、RT-06b 过接缝时位置平移 2πR，航向与速度不变，镜头没有插值跳动。
- **K9 主体**（R2）：总高 ≤ 1.75 m × s；两轮接地；轮角速度 = v / 0.3（±1%）；倾角、把手角与转向同号；俯仰等于坡度（±0.01 rad）；停住时单脚落地。
- **K10 性能**（Metal，每项新开浏览器，记录 GPU 字符串）：骑行机位 S0、A01 中段、W01、CR01 东南、RN01-03 跨中、RN01-05 洞内、LM07 西口，帧间隔中位数 ≤ 17 ms、p95 ≤ 25 ms；主体 ≤ 24 次绘制调用、≤ 30k 三角形；骑行逻辑（运动、碰撞、镜头）每帧 CPU ≤ 0.5 ms；自由视角默认机位的绘制调用不变（主体隐藏）。
- **K11 回归**：城镇里原 W9a 路线（RT-01、RT-02、RT-03 的城内段）照常可骑；城外随机 20 段走通。R1 起这两项取代 U7 的漫游部分，U7 的「相机 = 地面 + 1.62 m」改为：在平直、无遮挡处，6.7 的标称高度误差 ≤ 0.01 m × s。控制台无错误。
- **`views.mjs` 漫游项改写**：保留「V 键进入」「W 键移动」「跟随镜头离地」「拖动环视超过 90° 且不自动回正」（改测 lookYaw，航向不变）、「抓取方向」和三项触屏检查；退役「位置留在 layout.js 道路/巷道范围」「城镇西侧道路边界限制」「D/→ 向右、A 向左横移」，分别由 I1 可走面、碰撞探针和转向判号取代。
- **运行顺序**：`python3 build.py` → `node tools/measure_samples.mjs` → `node tools/layout_check.mjs --png` → `node tools/views.mjs` → `node tools/ride_check.mjs`，再加 `unify_check`、`road_check`、`transition_check`。截图与视频只生成、交给用户判断。

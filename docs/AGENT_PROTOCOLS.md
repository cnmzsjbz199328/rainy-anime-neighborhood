# Agent 协议：阶段细化、独立审查、返工、用户画面验收

适用于 [ROADMAP.md](../ROADMAP.md) 的所有阶段。每个阶段是单批次交付，所以开工前要对齐范围，交付后做机器审查并把需要人眼判断的画面交给用户验收，返工要有固定入口。仓库级默认规则见 [AGENTS.md](../AGENTS.md)；即使旧规格写着 Agent 查看最终截图，也按本协议执行。参考图可作为实现输入读取。

## 1. 阶段细化（每个阶段开工前，写进 PROGRESS，约 20 行）

在 PROGRESS.md 新增一节，标题 `<阶段> 阶段细化（日期）`，内容：

1. 本阶段的规格文件与设计卡/任务卡（路径）。
2. 范围：做什么、明确不做什么（引用规格的「范围」）。
3. 退出标准：分别列出机器可判定检查、规格要求生成的输出，以及需要用户验收的画面关卡（来自规格）。
4. 预算：性能、体积、时间；引用 ROADMAP 第 4 节第 6 条。
5. 风险与停止条件（来自规格与专项计划）。
6. 已知矛盾与你的裁决（卡片之间、参考图与规格之间）。

阶段规格要求截图时，记录生成条件和输出路径；画面判断由用户完成。只有用户在当前任务里明确点名某项画面检查，Agent 才能执行该项检查，且授权只覆盖点名内容。

写完直接开工，不等确认。若规格不存在或与现状矛盾，停下报告，不自行补规格（W 轨道请求执行 WS）。

## 2. 独立审查

交付后可另起一个 Agent，只审查，不改代码：

> /goal 读取 docs/AGENT_PROTOCOLS.md 的「独立审查」并审查 <阶段>

审查者的做法：

1. 读本阶段的规格、阶段细化、实施记录与最终提交（`git show`、`git diff <前一阶段>..HEAD`）。
2. 在干净工作树里重新构建，并按本阶段退出标准重跑相关机器检查，不引用交付者的结论。使用规格提供的 `--only`、`--views-only`、`--no-shots` 等筛选参数限定范围；不要因工具默认值跑入其他阶段或无关的长序列。
3. 不打开最终截图、图像或页面输出作视觉判断。可核对文件存在性、尺寸、元数据及机器指标；这些结果不能替代用户画面验收。若机器检查同时生成截图且不能关闭该副作用，报告输出路径，不据此作视觉结论。
4. 核对冻结数据未被改动、范围外文件未被改动、ROADMAP 与文档状态与事实一致。
5. 不修改任何文件。输出：
   - 结论：机器检查通过 / 机器检查有待办 / 机器检查不通过，并单独注明待用户验收的画面；
   - 每条检查的复跑结果；
   - 逐条问题（严重度：阻塞 / 应修 / 待办池；位置；复现方式）；
   - 面向用户的可复现看点清单；
   - 建议的返工指令。

需要视觉验收的阶段保持 `待确认`，直到用户确认。没有视觉验收闸门的阶段按其机器退出标准更新状态。

## 3. 返工

用户或审查者发现问题时：

> /goal 读取 docs/AGENT_PROTOCOLS.md 的「返工」并返工 <阶段>：<问题清单或审查报告路径>

返工 Agent：

1. 只修清单里的问题，不顺手扩大范围；每个问题一个小提交，提交信息写明问题编号。
2. 修完重跑受影响的检查与本阶段相关机器门槛；显式限定检查范围，不运行无关阶段的序列。
3. 更新实施记录：问题、原因、修复、复跑结果。
4. 把 ROADMAP 状态恢复到返工前应有的值，并按统一格式回复。

## 4. 用户画面验收交接

Agent 交付时列出短而可复现的看点清单。用户按需检查这些外观项目；Agent 不得自行勾选或写成已通过，除非用户明确授权本轮由 Agent 检查指定项目。

每个看点尽量写明：

- **位置/机位**：场景、方位、朝向、平面或球形模式、缩放距离；从默认机位操作时，写清操作步骤。
- **检查目标**：本轮改动和关键相邻连接、遮挡或轮廓应呈现什么。
- **预期与已知差异**：期望结果，以及已留给后续阶段处理的现象。
- **打开方式**：构建入口或用户可直接使用的页面；按阶段要求生成时附确切输出路径。

需要用户判断的外观项目可从下列清单中挑选，只列与本轮相关的项目：

- 雨线穿过屋顶、雨棚或室内。
- 物体悬空或陷入地面；台阶、花盆、设备、杆件没有落地。
- 同一平面上的闪烁（z-fighting）、玻璃或透明面闪烁、反光层穿插。
- 背面或侧面是空白墙；门窗只是贴图没有洞口（实心壳体）。
- 门净高、台面、层高与人体尺度不符；与相邻建筑比例失衡。
- 窗后看不到有用途的室内，或室内是发光空盒；外部光影与室内暖光冷暖关系错误。
- 文字不可读、被遮挡、方向镜像或使用了参考图中的不可靠文字。
- 墨线每帧抖动、线宽不一致、墨线缺失造成风格断裂。
- 法线错误形成的黑面或过亮面；弯曲后接缝裂开。
- 与邻栋互相遮挡主要立面；该建筑成为全城最亮的东西（便利店除外）。
- 全城视角下的轮廓、屋顶层次与周围不协调。
- 页面控制台有错误或警告（由机器检查输出报告，不属于视觉判断）。

交付摘要应区分机器结果和用户验收状态，例如：“机器检查通过；以下画面待用户验收。”不得写“视觉通过”。

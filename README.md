## 运行

直接使用现代浏览器打开 `index.html`，无需安装依赖或访问外部 CDN。浏览器需要支持 WebGL。也可以运行 `python3 -m http.server 8000`，然后访问 http://localhost:8000。

平面模式自由视角：拖动旋转，滚轮或双指缩放。平移（移动旋转中心）有四种方式：鼠标右键拖动、Shift/Ctrl + 左键拖动、触屏双指拖动，或 WASD/方向键（相对当前视线方向）。按 V 或右上角的「骑行」进入第三视角骑行（平面与球形地图上任何道路都可骑，从视线目标最近的车行道出发、离目标超过 2 m 时屏幕下方提示出发道路；地图切换动画进行中暂不能开始骑行，屏幕下方会提示）。骑行时 W/↑ 前进加速、S/↓ 刹车（停住后继续按倒推）、A/← 左转、D/→ 右转（停住时原地扶车转向）；拖动画面 360° 环视（不改行进方向、不自动回正，抓取式），滚轮调跟随距离，C 或双击画面回正；触屏用左下摇杆（上下前进/刹车、左右转向），摇杆以外单指拖动环视、双指捏合调距离、双击回正。人行道徐行、只能经坡口或车道口上下路缘；石阶与检修梯自动下车推行。V、Esc 或按钮回到自由视角，视线目标留在骑手当前位置（桥上、隧道里保持所在层），任何时候都可退出（包括地图切换中）。骑行中点「球形地图」/「平面地图」不退出骑行：同一骑手继续行驶，镜头跟随，约 2 秒的切换中照常操作，再按一次可中途反向（W9b，[计划](docs/world/SPHERE_RIDING_PLAN.md)）。平面地图是雨夜与当地天气，球形地图始终是晴朗白天（D9），天气与日光跟随骑手所在位置；场景动画在两种视角下持续运行。

第三视角骑行（[计划](docs/world/THIRD_PERSON_ROAM_PLAN.md)）：R1 起骑行取代步行，是唯一的漫游；R2 起可见原创鹈鹕骑手与自行车，追随镜头会避开建筑、地形与隧道衬砌。鹈鹕、自行车与骑行动画耦合移植自 [riba2534/claude-opus-5-5-demo 的 pelican-bike](https://github.com/riba2534/claude-opus-5-5-demo/tree/54adc1fb64155f9dd7c1c90ecae7b8185ac540b8/pelican-bike)（固定提交 `54adc1fb64155f9dd7c1c90ecae7b8185ac540b8`；`src/pelican.js`、`src/bicycle.js`、`src/util.js` 与 `src/main.js` 的 `updateRide`；经项目所有者确认可直接使用），改为本项目的 toon、墨线与纸纹，雨具与车篮见 [R2 设计卡](docs/world/R2_RIDER_CARD.md)。固定检查路线与数据校验 `node tools/ride_routes.mjs`（只读 `world.js`、`layout.js`）；浏览器检查 `node tools/ride_check.mjs [--only K1,…] [--routes all|RT-01,…]`（K1–K4、K6–K8、K11）。

球形地图：点击「球形地图」切换。左键或单指拖动抓取并转动星球，可连续翻过两极；右键、Shift/Ctrl + 左键或双指拖动环视，俯仰可到正上方。滚轮或双指捏合缩放（9–400 m）；WASD/方向键沿当前视线在球面移动，速度最高 40 m/s。拉远时星球自动居中，切回平面时目标纬度限制到 ±80°。球形地图上同样按 V 骑行（从视线方向在出生点切平面上的投影定车头朝向），骑行时拖动只环视、滚轮/双指只调跟随距离，不转动星球；骑行只覆盖现有路网。

## 部署到 Cloudflare Workers

`wrangler.jsonc` 将项目配置为纯静态资源 Worker；`.assetsignore` 保证只公开 `index.html`。

通过 Cloudflare 的 Git 集成自动部署（Workers Builds）：

1. Cloudflare 控制台 → Workers & Pages → Create → Import a repository，选择本仓库。
2. 项目名填 `rainy-anime-neighborhood`（需与 `wrangler.jsonc` 中的 `name` 一致）。
3. Build command 留空（`index.html` 已提交在仓库中）；Deploy command 保持 `npx wrangler deploy`。
4. 保存后，每次推送到 `main` 都会自动部署到 `https://rainy-anime-neighborhood.<子域>.workers.dev`。

也可以本地手动部署：`npx wrangler login && npx wrangler deploy`。
